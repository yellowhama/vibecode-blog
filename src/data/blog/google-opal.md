## Where Does Opal Fit Right Now?

### vs ChatGPT / Claude

ChatGPT and Claude are **conversational AI**. You ask, they answer. Ask for code, they give you code. But they don't **run it or build an app for you**.

Opal is different. Say "make me an SEO content writer" and it:

- Designs the workflow
- Builds the UI
- Spits out a working mini-app

**Not an "answer." A deliverable.**

### vs n8n / Zapier / Make

n8n, Zapier, Make are **workflow automation tools**. Powerful, but there's a learning curve. Connect nodes, set triggers, plug in API keys.

Opal? Just **describe what you want**. "When I get an email, send a Slack notification." That's it. Beyond no-code — closer to **no-touch**.

But for complex multi-step automations or external API integrations, n8n/Zapier still wins. Opal is optimized for **quick prototyping and simple workflows**.

### vs Claude Artifacts / GPT Canvas

Claude's Artifacts and GPT's Canvas can "build" things too. But those are **temporary creations inside a conversation**.

Opal builds **standalone mini-apps**. They're saved, shareable, usable by others. There's a "remix" feature — copy someone else's app and customize it.

## Limits and Caveats

### What It Can Do

- Quick prototyping
- Simple workflow automation
- Content generation (text, image, video)
- Idea validation
- Mini-app sharing and remix

### What It Can't Do (Yet)

- Complex multi-step automation (n8n/Zapier is better)
- External API integration (limited)
- Production-grade app deployment
- Database integration
- **No custom domain linking**
- **No exporting as standalone app** (only works inside Opal's platform)
- **Not suited for enterprise deployment**

### Watch Out For

- Won't work 100% perfectly. Test everything
- Output quality depends on your prompt
- Be careful with sensitive data
- It's beta — features change frequently

## Common Questions

### "I'm not technical. Can I do this?"

Yes. The whole point of Opal is **"just say what you want."** You don't need to know how it works.

### "I use Zapier/n8n. Why would I need Opal?"

Different use cases.

- **Zapier/n8n**: Complex automation, external service integrations, production
- **Opal**: Quick prototyping, idea validation, simple workflows

Use both. Validate fast with Opal. If it works, build properly with n8n.

### "It says free. Is it actually free?"

As of now, completely free. Just need a Google account. But it's beta, so paid tiers could come later.

### "How is this different from Claude Code?"

- **Claude Code**: Terminal-based, real code generation, production-grade development
- **Opal**: Web-based, no-code mini-apps, quick prototyping

Claude Code is "development." Opal is "automation and prototyping."
