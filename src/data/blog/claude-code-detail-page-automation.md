# 클로드 코드로 상세 페이지 100% 자동화하기

> 출처: [무료 소스 제공] 99%가 모르고 있는 클로드 코드 상세페이지 100% 완전 자동화 방법
> YouTube: https://www.youtube.com/watch?v=ysA5Wd_o4_Q

---

## 개요

클로드 코드의 에이전트 팀 기능을 활용하여 상세 페이지(제품 랜딩 페이지)를 100% 자동화하는 방법. 기획, 카피라이팅, 디자인, 이미지 생성까지 전 과정을 에이전트가 처리한다.

일반적으로 상세 페이지 외주 비용은 **100만~500만원** 수준이며, 기획-디자인-수정 과정이 포함되어 있다.

---

## 에이전트 팀 구조

### 전체 파이프라인

```
입력 수집 → 리서치 → 카피라이팅 → 디자인 방향 설정 → 프롬프트 생성 → 이미지 생성(13장) → 최종 합본
```

### 에이전트 역할

| 에이전트 | 역할 | 산출물 |
|----------|------|--------|
| **오케스트레이터** | 메인 컨트롤러, 에이전트 동적 호출 | 전체 흐름 관리 |
| **정보 수집 (Intake)** | 사용자 입력 수집, 요건 정리 | 제품/서비스 정보 |
| **리서치** | 웹에서 관련 정보 수집 | 시장/경쟁 분석 |
| **카피라이팅** | 세일즈 카피 작성 (팔리는 글쓰기) | 섹션별 카피 텍스트 |
| **디자인** | 스타일, 컬러 결정 | 디자인 방향 가이드 |
| **프롬프팅** | Gemini 3 Pro용 이미지 생성 프롬프트 작성 | 13개 이미지 프롬프트 |

### 최종 결과물

- PNG 이미지 13장 (각 1200x1200)
- Python 스크립트로 이미지 자동 합본
- 필요 시 PDF 브로셔로 변환 가능

## 핵심 셋업 3단계

### 1단계: 에이전트 팀 생성

클로드 코드의 **공식 서브 에이전트와 스킬** 가이드라인을 따라야 한다.

**핵심 파일 구조:**
- `.claude/agents/` 폴더에 **마크다운(.md) 파일**로 에이전트 정의
- `.claude/skills/` 폴더에 스킬 파일 배치

```
프로젝트/
├── .claude/
│   ├── agents/
│   │   ├── orchestrator.md
│   │   ├── intake.md
│   │   ├── research.md
│   │   ├── copywriting.md
│   │   ├── design.md
│   │   └── prompting.md
│   └── skills/
│       └── ...
```

**주의:** 에이전트는 반드시 `.md` 파일로 작성해야 한다. JSON이나 Python만으로 구성하면 안 됨.

**프롬프트 예시:**
```
상세 페이지 에이전트 팀을 만들고 싶어.
정보 수집 에이전트, 리서치 에이전트, 카피라이팅 에이전트, 디자인 에이전트, 프롬프팅 에이전트
개발용 구조도를 제시해 줘.
클로드 코드의 공식 서브 에이전트와 스킬을 참고해서 만들어 줘.
```

### 2단계: 13단계 랜딩 페이지 설계도 학습

상세 페이지의 **설득 구조**를 정의한 플랜 파일을 작성하여 에이전트에 학습시킨다.

**13단계 상세 페이지 구조:**

| 순서 | 섹션 | 목적 |
|------|------|------|
| 1 | 긴급성 헤더 | 3초 안에 시선 멈추기 |
| 2 | 공감 섹션 | "이거 내 얘기네" 공감 유발 |
| 3 | 페인포인트 나열 | 고객의 아픔/고민 구체화 |
| 4 | 문제 정의 | 왜 이런 일이 생기는지 설명 |
| 5 | 변화 스토리 | 변화의 가능성 제시 |
| 6 | 솔루션 소개 | 우리 제품/서비스 제시 |
| 7 | 제품 상세 | 단계별 사용법 (Step 1, 2, 3...) |
| 8 | 성분/스펙 | 검증된 성분, 기술 스펙 |
| 9 | 비포/애프터 | 사용 전후 비교 |
| 10 | 사용자 후기 | 실제 리뷰/평가 |
| 11 | 세트 구성 | 구성품 안내 |
| 12 | FAQ | 자주 묻는 질문 |
| 13 | CTA (마무리) | "지금이 가장 좋은 기회입니다" |

**학습 방법:**
```
/s landing.plan을 참고해서 시스템 프롬프트에 잘 학습시켜 줘
```

### 3단계: Gemini API 키 연동

이미지 생성에 **Gemini 3 Pro API**를 사용한다.

1. [AI Studio](https://aistudio.google.com) 접속
2. "Get API Key" 클릭 → 새 API 키 생성
3. Google Cloud Console에서 결제 계정 연동 필요
4. 프로젝트 루트에 `.env` 파일 생성:

```env
GEMINI_API_KEY=여기에_API_키_붙여넣기
```

5. 클로드 코드에 알려주기:
```
.env 파일을 불러와. Gemini API 키는 여기에 있으니 에이전트가 참고하도록 해.
```

## 실행 및 최적화

### 기본 실행

```
상세 페이지 하나 테스트로 만들어 줘
```

### 최적화 팁

1차 결과물 이후 반복 수정으로 품질 향상:

```
전체 이미지들의 가로 세로 높이를 1200으로 고정해 줘
모델의 등장 비율을 더 높여 줘
제품 디테일을 더 살려 줘
만화 같은 이미지는 없애 줘
실제 사람 얼굴이 나오게 만들어 줘
```

### 제품 이미지 활용

- 실제 제품 이미지를 클로드 코드에 붙여넣기 (Ctrl+V)
- "이 이미지를 바탕으로 상세 페이지를 만들어 줘"

### 결과물 활용 방식

1. 초안으로 전체 13장 이미지 생성
2. 섹션별 세부 수정 요청
3. 리뷰/모델/텍스트 등 개별 교체
4. 최종 합본 후 스마트스토어 등에 업로드

## 주의사항

- 에이전트는 반드시 클로드 코드 공식 가이드라인(서브 에이전트, 스킬)을 따를 것
- 에이전트 정의는 `.md` 파일로 작성 (JSON/Python만으로는 부족)
- Gemini API 결제 연동 필수
- 결과물은 **초안**으로 취급하고, 실제 판매 전 반드시 검수/수정
- 저작권 있는 이미지 사용 주의
- 소스 코드는 영상 설명란의 GitHub에서 다운로드 가능
