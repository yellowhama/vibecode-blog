# 6. Twitter/X Tech Creator Growth Strategy

## 1. X 알고리즘 (2026)

### 핵심 랭킹 시그널
| 액션 | 상대적 가중치 | 비고 |
|------|------------|------|
| Reply (상호 대화) | 150x (like 대비) | 최고 시그널 |
| Reply (일방) | 27x | 2등 시그널 |
| Quote Tweet | 25x | 3등 |
| Profile Click | 12x | 높음 |
| Bookmark | 높은 배수 | 명확한 수치 미공개 |
| Repost | 중간 | - |
| Like | 1x (기준) | 최저 |

### 시간 감쇄
- 트윗 반감기: 6시간 (일부 자료: 52분)
- 최초 30분 결정적: 초기 참여가 "For You" 피드 진입 결정
- 24시간 후 알고리즘 배포 최소화

### 외부 링크 패널티
- 링크 포함 트윗은 거의 제로 배포 (특히 비-Premium)
- 해결: 링크를 리플라이에 넣기

### Grok 기반 Phoenix Scorer
- P(like), P(reply), P(repost), P(click) 예측
- Weighted Score = Σ (weight × P(action))

## 2. 개발자 Twitter 성장 전략

### 핵심 공식
- 70% 참여 (리플라이, 토론, DM) + 30% 콘텐츠 창작
- 50K+ 팔로워 크리에이터 전원이 peer 네트워크 보유

### 일일 최소 활동
| 활동 | 빈도 |
|------|------|
| 오리지널 트윗 | 3-5/일 |
| 니치 내 리플라이 | 20+/일 |
| 스레드 | 1/주 |
| DM (니치 연결) | 5/일 |
| 롱폼 콘텐츠 | 1 스레드/주 |

### 성장 타임라인
- 12주 일관 포스팅 → 초기 트랙션
- 월 30-50% 팔로워 성장 (일관 활동 시)
- 0→1,000: ~90일
- 1,000→10,000: 6-12개월

## 3. 바이럴 스레드 공식

### 최적 길이: 8-12 트윗
- 5 미만: 스레드 포맷 불필요
- 15 초과: 독자 이탈
- 스레드가 단독 트윗 대비 2.4-3x 참여

### 훅 공식 3가지
1. **패턴 중단**: "I spent $0 on marketing and got 10K users in 30 days."
2. **구체성**: "7 VS Code extensions that saved me 2 hours every day"
3. **직접 혜택**: "I went from 0 to $10K MRR. Here's the exact stack:"

### 스레드 구조
| 트윗 | 목적 |
|------|------|
| 1번 | 훅 — 스크롤 멈추기 |
| 2-9번 | 본문 — 트윗당 핵심 인사이트 1개, 250자 이내 |
| 10-11번 | 클라이맥스 — 가장 가치 있는 인사이트 |
| 마지막 | CTA — 팔로우, 공유, 뉴스레터 구독 |

### 퍼포먼스 부스터
- 1인칭("I") → 23% 더 높은 참여
- 이미지 포함 → 40% 높은 완독률
- 넘버링 ("7 tools", "5 mistakes") → 기대치 설정

## 5. Twitter → 뉴스레터 퍼널

### 바이오 최적화
- 공식: "I help [대상] achieve [결과]. [증거]"
- 예: "I help bootstrapped founders reach 10K MRR. Weekly thread on what actually works."
- 실제 얼굴 사진 (아바타/로고는 팔로우율↓)
- 완성된 바이오 → 3x 프로필 방문

### 핀 트윗
3가지 중 하나:
1. 자기 소개
2. 최고 퍼포먼스 스레드
3. 현재 캠페인 (뉴스레터 가입)

### 스레드→뉴스레터 전환
1. 가치 있는 스레드 (상호주의 구축)
2. 마지막 트윗: "매주 더 깊은 인사이트를 뉴스레터로 공유. 구독: [리플라이 링크]"
3. 링크는 리플라이에 (알고리즘 패널티 회피)

## 6. 콘텐츠 유형 (참여도 순)

1. **핫테이크/반대 의견** — 최고 참여. 리플라이 체인 유발
2. **Build-in-Public 매출/메트릭** — 숫자 + 투명성 = 도파민
3. **코드 스크린샷 튜토리얼 스레드** — 비주얼 코드 > 텍스트 코드
4. **TIL (오늘 배운 것)** — 짧고, 놀랍고, 공유 가능
5. **도구 추천** — 북마크 유발 (북마크 = 알고리즘 부스트)
6. **밈** — 메시지와 연결되면 효과적
7. **코드 스니펫/팁** — 짧고 실행 가능
8. **스토리텔링** — "프로덕션 서버가 다운된 날..."
9. **실수 포스트** — 취약성 + 학습
10. **링크 포스트** — 최악 (알고리즘 패널티)

### 콘텐츠 믹스
| 유형 | 비율 | 목적 |
|------|------|------|
| 교육/가치 | 40% | 전문성 구축 |
| 의견/핫테이크 | 20% | 참여 유도 |
| Build-in-public | 15% | 커뮤니티 구축 |
| 참여 (리플라이, QT) | 15% | 네트워크 성장 |
| 프로모션 | 10% | 뉴스레터/제품 전환 |

## 7. 포스팅 타이밍 & 빈도

### 최적 시간 (테크 오디언스)
- 수요일 9AM-12PM — 최고 참여
- 화요일, 목요일 10AM-2PM — 2위, 3위
- 주말: 낮은 참여, 대량 포스팅 피하기
- 글로벌: 9-11 AM EST 최적

### 빈도
| 단계 | 트윗/일 | 스레드/주 |
|------|---------|---------|
| 0-1K | 3-5 | 1 |
| 1K-10K | 5-10 | 1-2 |
| 10K+ | 3-5 고품질 | 2-3 |

### 규칙
- 트윗 간 30-60분 대기
- 품질 > 수량: Like 50개 트윗 1개 > Like 0개 트윗 10개
- 일관성 > 강도: 매일 안 빠지기 > 간헐적 폭발

## 10. 플레이북 요약

### Phase 1 (Week 1-4): 기반
- X Premium 가입 ($8/mo)
- 바이오 최적화 + 핀 트윗
- 15-20 인플루언서 프라이빗 리스트
- 매일 3 트윗 + 20 참여

### Phase 2 (Week 5-12): 성장
- 주 1 스레드 (훅-본문-CTA)
- 70% 참여, 30% 콘텐츠
- 큰 계정에 60분 내 리플라이
- Build-in-public 시작

### Phase 3 (Week 13+): 전환
- 뉴스레터 런치 + 바이오 링크
- 스레드→뉴스레터 CTA 퍼널
- Twitter Space 호스팅/참여
- 목표: 12주에 1,000, 6개월에 5,000+

### 최중요 규칙
**대화 깊이가 모든 것을 지배한다.** 진정한 리플라이 체인 1개 = 수백 개 좋아요. 알고리즘은 실제 대화에 보상하도록 설계됨.
