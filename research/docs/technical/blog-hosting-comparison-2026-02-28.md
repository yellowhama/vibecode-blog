# 블로그 호스팅 비교 — VPS vs Vercel + 결제 전략

> Date: 2026-02-28
> Context: 한국 개인 크리에이터, Stripe 사용 불가, Paddle MoR 사용 예정

---

## 1. 한국에서 Stripe가 안 되는 문제

- **한국 법인/개인사업자는 Stripe 계정 개설 불가** (2026년 현재)
- "한국 원화 결제 지원" = 해외 Stripe 계정이 한국 고객 카드를 받는 것
- 한국 금융 규제 때문에 Stripe 한국 지사가 없으면 불가능
- Ghost, Gumroad, Ko-fi, Buy Me a Coffee 등 Stripe 의존 서비스는 **한국 판매자로서 결제 수령 불가**

### 대안: Paddle (Merchant of Record)

| 항목 | 내용 |
|------|------|
| 한국 판매자 가입 | **가능** (명확히 지원) |
| 수수료 | 5% + $0.50/건 |
| 해외 거래 추가 수수료 | **없음** (Lemon Squeezy는 +1.5%) |
| 한국 고객 결제 수단 | 카카오페이, 네이버페이, 카드 |
| 세금/VAT | **100개국+ 자동 처리** (계산, 징수, 신고, 납부 전부) |
| 차지백/사기 방지 | Paddle이 부담 |
| 송금 | Wire Transfer ($15/건) 또는 Payoneer ($4/건) |
| 최소 송금액 | $100 |

### Paddle vs 다른 MoR

| 플랫폼 | 한국 지원 | 수수료 | 비고 |
|--------|----------|--------|------|
| **Paddle** | **O** | 5% + $0.50 | 추가 수수료 없음, 한국 결제수단 |
| Lemon Squeezy | 불명확 | 5% + $0.50 + 1.5%(해외) | Stripe 인수 후 축소 |
| Gumroad | 불명확 | 10% | PayPal 연동 종료 |
| Patreon | O | 5~12% | 커스터마이징 제한 |

## 2. Vercel 무료 티어 한계

| 제한 | 무료 (Hobby) | Pro ($20/월) |
|------|-------------|-------------|
| 대역폭 | **100GB/월** | 1TB/월 |
| 서버리스 실행 | 100GB-시간 | 1,000GB-시간 |
| 빌드 시간 | 100시간/월 | 400시간/월 |
| 이미지 최적화 | 1,000개/월 | 5,000개/월 |
| 분석 | 2,500 이벤트/월 | 25,000 이벤트/월 |
| **상업 이용** | **불가** | 가능 |
| Cron Jobs | 2개 (1일 1회) | 40개 (5분 간격) |

**핵심**: Paddle로 돈 받는 순간 상업 이용 → **Vercel Pro($20/월) 필수**.

## 3. VPS vs Vercel Pro 비교

### 가격

| 항목 | Hetzner VPS (CX22) | Vercel Pro |
|------|-------------------|------------|
| 월 비용 | **$4.50** | **$20** |
| 대역폭 | **20TB** | 1TB |
| 스토리지 | 40GB SSD | 없음 (정적 배포) |
| CPU/RAM | 2 vCPU / 4GB | 서버리스 |
| 상업 이용 | 제한 없음 | 가능 |

**VPS가 4배 싸고, 대역폭은 20배.**

### 기능 비교

| 항목 | VPS | Vercel |
|------|-----|--------|
| 자동 스케일링 | X (수동) | **O** (자동) |
| 글로벌 CDN | Cloudflare 무료 추가 | **내장** |
| SSL | Let's Encrypt (무료) | **자동** |
| 배포 | git push + 빌드 스크립트 | **git push → 자동** |
| 서버사이드 자유도 | **무제한** (Cron, WebSocket, DB, 장기 프로세스) | 서버리스 제한 (타임아웃, 상태 없음) |
| DB | **직접 설치** (PostgreSQL, MySQL, SQLite) | 외부 서비스 (Supabase, PlanetScale) |
| Webhook 안정성 | **항상 ON** (콜드 스타트 없음) | 콜드 스타트 가능 |
| 벤더 종속 | **없음** | Vercel 정책/가격에 종속 |
| 유지보수 | OS 업데이트, 보안, 백업 **직접** | **없음** (Vercel 관리) |
| 장애 대응 | **직접** (새벽 3시 서버 다운 = 내 문제) | Vercel이 처리 |
| 여러 서비스 동시 운영 | **가능** (블로그 + API + DB + 뭐든) | 프로젝트별 과금 |

### 트래픽 기준 비용 비교

| 월 페이지뷰 | Vercel | VPS (Hetzner) |
|------------|--------|---------------|
| 1만 | $20 (Pro 최소) | $4.50 |
| 10만 | $20 | $4.50 |
| 100만 | $20 + 대역폭 초과 가능 | $4.50 (20TB 내) |
| 1,000만 | $20 + 추가 과금 | $4.50 + Cloudflare |

블로그 글 하나 ~50KB 기준:
- Vercel 무료 100GB = **200만 PV/월**
- Hetzner 20TB = **4억 PV/월**

## 4. VPS 장점 요약

### 돈을 벌 거라면 VPS가 합리적

1. **상업 이용 제한 없음** — 수익 발생해도 추가 비용 없음
2. **가격 대비 자원 압도적** — $4.50에 20TB, Vercel $20에 1TB
3. **벤더 종속 없음** — Vercel 가격 인상/정책 변경에 안 물림
4. **서버사이드 완전 자유** — Cron, WebSocket, 장기 실행, DB 직접 운영
5. **Webhook 안정** — 항상 켜져 있어서 Paddle 이벤트 놓칠 일 없음
6. **한 서버에 여러 서비스** — 블로그 + API + DB + 나중에 추가 서비스 전부 한 곳에

### VPS 단점

1. **유지보수는 내 몫** — OS 업데이트, 보안 패치, 백업
2. **장애 대응 직접** — 서버 죽으면 내가 살려야 함
3. **배포 파이프라인 직접 구축** — git push → 빌드 → 서빙 자동화 필요
4. **스케일링 수동** — 트래픽 폭증 시 서버 업그레이드 직접

## 5. 단계별 전략

```
Phase 1: 런칭 (수익 없음, 트래픽 적음)
  → Vercel 무료 OK
  → 글 쓰고 독자 모으기에 집중
  → 비용: $0

Phase 2: 수익화 시작 (Paddle 연동)
  → 상업 이용 → Vercel Pro ($20/월) 또는 VPS ($4.50/월)
  → VPS가 4배 싸지만, 관리 부담 감수해야 함
  → 판단 기준: 서버 관리 할 줄 아냐 / 시간이 있냐

Phase 3: 성장 (트래픽 증가)
  → VPS + Cloudflare CDN (가성비 최강)
  → 또는 Vercel Pro 유지 (편하지만 비쌈)

Phase 4: 스케일 (트래픽 폭증)
  → VPS 업그레이드 ($9~24/월) + Cloudflare
  → 또는 VPS 여러 대 + 로드밸런서
```

## 7. 기술 스택 후보

### A. Next.js + Paddle + Supabase (현재 스택 활용)

```
Next.js (SSG/SSR) → Vercel 또는 VPS
Supabase          → 인증 + 구독자 DB (무료 티어)
Paddle            → 결제 (카카오페이, 네이버페이)
Stibee            → 뉴스레터 (한국 서비스, 300명 무료)
```

- 장점: 이미 알고 있는 스택, musu.pro 경험 활용
- 단점: CMS 없음 (MDX 파일로 글 관리)

### B. Astro + Paddle (콘텐츠 퍼스트)

```
Astro (SSG)       → JS 0 기본, 아일랜드 아키텍처
Content Collections → 마크다운/MDX 네이티브
Paddle            → 결제
```

- 장점: 블로그 특화, 95+ Lighthouse 기본, 번들 최소
- 단점: 새 프레임워크 학습

### C. Zola (Rust, 극한 성능)

```
Zola (SSG)        → Rust 바이너리, 50페이지 36ms 빌드
Tera 템플릿       → Jinja2 스타일
Paddle            → JS 오버레이로 결제
```

- 장점: 빌드 최빠름, 바이너리 하나, 의존성 0
- 단점: 생태계 작음, 인터랙티브 기능 수동 구현

## 8. 핵심 결론

> **Paddle로 돈 받을 거면, Vercel 무료는 상업 이용 불가라서 어차피 유료 전환 필요.**
> **그 시점에서 Vercel Pro($20) vs VPS($4.50)를 비교하면, VPS가 4배 싸고 자유도 압도적.**
> **초기에는 Vercel 무료로 시작, 수익화 시점에 VPS 전환이 가장 현실적.**
