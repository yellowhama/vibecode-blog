## 목적

이미 Cursor, Claude Desktop, MCP 등을 쓰면서 세팅 지옥과 기기 파편화에 지친 **파워 유저**들에게
"기존 툴을 대체하지 않고, 품고 굴리는 운영체제"라는 확신을 주는 것.

**서브:**

> 더 쉽고, 간편하고, 안전하게 지휘하는 **단 하나의 운영체제(OS)**입니다.

**CTA 버튼:**

## 블록 2: Vampire Strategy (Zero Setup)

### 레이아웃
- 좌측 텍스트 / 우측 UI 목업 스크린샷

### 카피

**섹션 타이틀:**
> **세팅 지옥의 끝. 당신이 쓰던 툴, 1초 만에 흡수합니다.**

**상세:**
> 새로운 툴 쓸 때마다 또 터미널 열고 JSON 파일 만지실 겁니까?
>
> MUSU는 당신이 기존에 피 토하며 맞춰둔 도구(MCP)와 스킬(`.cursorrules`)을
> 완벽하게 스캔합니다.
>
> 단 한 번의 클릭으로 기존 세팅을 MUSU의 통제망 안에 쓸어 담으십시오.

### 우측 UI 목업
- 팝업창 형태
- 내용: "기존 MCP 도구 4개를 발견했습니다. MUSU 통제망에 동기화 중... [ 95% ]"
- 발견된 도구 리스트: filesystem, postgres, github, slack 등

## 블록 3: Warden System (The Warden)

### 레이아웃
- 3열 카드형 UI (가로 3개 배치)

### 섹션 타이틀
> **AI에게 백지수표를 쥐여주지 마십시오. 통제하십시오.**

### 카드 1: 토큰 다이어트 (JIT Tooling)
> AI가 멍청해지지 않게, 100개의 도구 중 지금 당장 필요한 1개만
> 입에 떠먹여 줍니다. API 요금 폭탄을 막으십시오.

### 카드 2: 절대적 방화벽 (JSON-RPC Interceptor)
> AI가 시스템 파괴 명령어나 허락 없는 DB 삭제를 시도합니까?
> MUSU가 중간에서 패킷을 뜯어보고 즉시 차단합니다 (BLOCK).

### 카드 3: OS 네이티브 금고 (Keyring)
> 터미널에서 `sudo` 비번 치는 공포는 끝났습니다.
> 군사급 보안 금고에 딱 한 번만 저장하면,
> MUSU가 백그라운드에서 조용히 권한을 꽂아 넣습니다.

## 블록 4: Zero Data Leak (보안/프라이버시)

### 레이아웃
- 풀 와이드 배경 (약간 더 밝은 서피스 컬러 #1A1A22)
- 중앙 정렬 텍스트

### 섹션 타이틀
> **당신의 소스코드는 단 1바이트도 우리의 서버로 올라가지 않습니다.**

### 서브 타이틀
> **MUSU는 통제할 뿐, 훔쳐보지 않습니다.**

### 상세
> 당신이 짠 코드, 실행되는 파일, 연결된 MCP 데이터베이스의 내용물...
> 그 어느 것 하나 당신의 컴퓨터(하드디스크)를 떠나지 않습니다.
>
> 당신이 입력한 결제용 계정정보 이외의 것은
> 어느 하나 서버로 올라가지 않습니다.
>
> HiveLink로 원격 접속할 때도, 데이터는 중간 서버를 거치지 않고
> 당신의 기기 간에만 P2P(QUIC)로 암호화되어 직결됩니다.

### 보안 배지 (3개, 인라인)
- **HMAC-SHA256 서명 인증** — 네트워크 패킷 위조/재전송 차단
- **Fail-Closed 정책** — 모르면 일단 막는다. 허락 없으면 실행 없음.
- **DLP 내장** — 시크릿 키/비밀번호 유출 자동 차단

### 기술적 근거 (접히는 세부사항, 선택적)
> 849 Rust core tests · 5,400+ TypeScript tests · 40,000+ lines of Rust
> docs/code 보안 정합성 CI 자동 검증 · 6-layer 보안 스캔 파이프라인

## 블록 5: HiveLink Grid (원격 분산 실행)

### 레이아웃
- 좌측 네트워크 다이어그램 / 우측 텍스트

### 섹션 타이틀
> **스타벅스의 낡은 노트북이 댁의 4090 GPU를 부려먹습니다.**

### 상세
> 기기의 물리적 한계? MUSU에 내장된 Link 원격 분산망이 박살 냅니다.
>
> 카페에서 가볍게 명령만 내리십시오.
> 무거운 영상 렌더링은 집에 있는 데스크탑이,
> 기밀 데이터 분석은 사무실의 NAS가 처리합니다.
>
> 전 세계에 흩어진 당신의 컴퓨터들이
> MUSU 안에서 하나의 거대한 AI 도구 상자로 통합됩니다.

### 좌측 비주얼
- 맥북(프롬프트 입력) → 점선(QUIC P2P 통신) → 윈도우 데스크탑(렌더링 중)
- 또는: 3기기 삼각형 구조 (노트북 / 데스크탑 / NAS)
- 중앙에 "MUSU" 허브 표시

### 핵심 강조
- 중간 서버 없음 (P2P 직결)
- 데이터는 기기 간에만 이동 (Zero Data Leak와 연결)

## Landing 1과의 연결
