# Web Design Resources (2025)

> Source: [20 Top Underrated Web Design Resources for 2025](https://www.youtube.com/watch?v=eeN7yUcIWbw)

---

## UI Elements & Components

### 1. UI Verse (uiverse.io)
- Buttons, animations, UI elements
- "Copy to Figma" one-click export
- Use case: Pre-built UI components when starting from scratch

### 2. Isocons
- Isometric icon library
- Customizable: rounded/sharp, stroke weight
- Batch export via "Add to folder" checkout flow
- Use case: Isometric diagrams, feature illustrations

### 3. Handy Arrows
- Arrow graphics library with serious variety
- Beyond what Figma's pencil tool can do
- Use case: Flow diagrams, annotations, playful UI accents

---

## Logos & Branding

### 4. Logo System
- Curated logo library with interesting visual backgrounds
- Use case: Logo inspiration and reference

### 5. Logo Ipsum
- Placeholder logos, instant copy
- Use case: Mockups, wireframes, placeholder branding

### 6. logo.com
- Logo generation tool
- Use case: Quick logo drafts

---

## Typography

### 7. Fonty
- Automatic font pairing using 3D-mapped font relationships
- One-click custom pairing
- Use case: Font pairing decisions (especially for non-type designers)

### 8. Typefaces.today
- Curated display font collection
- Smaller but high-quality selection
- Use case: Finding distinctive headline/display fonts

---

## Visual Effects & 3D

### 9. Phase
- Animate Figma designs directly
- Editor similar to Figma (easier than After Effects)
- Use case: Motion design, animated prototypes

### 10. Derves
- 3D effects with interactive sliders
- Use case: Crypto, SaaS, modern tech landing pages

### 11. Endless Tools
- Customizable 3D resources
- Growing library
- Use case: 3D illustrations, hero visuals

### 12. Photo Gradient
- Mesh gradient generator with extensive presets
- More control than Figma's native tools
- Refresh page for new color combinations
- Use case: Hero backgrounds, gradient overlays

---

## Design Inspiration & Reference

### 13. Nukes
- Trending/top designs curated from Twitter
- Design, branding, 3D effects
- "Like Dribbble but on steroids"
- Use case: Trend tracking, cutting-edge design reference

### 14. Design Spells
- Curated micro interactions from major brands
- Million/billion dollar company examples
- Use case: Micro interaction ideas, animation reference

### 15. Unsectioned
- Websites chopped into individual sections, made searchable
- Use case: Layout reference for specific section types (hero, pricing, CTA, etc.)

### 16. UX of AI
- AI product UX patterns and references
- Use case: Designing AI-adjacent interfaces and interactions

### 17. Wall of Portfolios
- Portfolio showcase with designer experience level, location, work type
- Helps contextualize skill level vs. output
- Use case: Portfolio benchmarking, realistic expectation setting

---

## Design Kits & Templates

### 18. Relume
- AI site builder + massive Figma design kit
- ~54 pages of sections, layouts, and elements
- Available as Figma Community file (no signup needed)
- Use case: Section layout starting points, rapid wireframing

---

## Stock Photos

### 19. Shopify Burst
- Free stock photos by Shopify
- Less extensive than Pexels but better organized
- Use case: E-commerce, product, lifestyle photography

---

## Podcasts & Community

### 20. Design Sphere
- Web design podcast curation
- Notable: "Honest UX Talks"
- Use case: Background listening while designing

### Bonus: L Files Playlists
- Music playlists curated by professional designers
- Use case: Focus/flow state while working
