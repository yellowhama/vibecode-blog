## 유저측 장점 (핵심)

당신의 코드, 파일, 어느것 하나 당신의 컴퓨터를 떠나지 않습니다.
당신이 입력한 계정정보 이외의 것은 어느 하나 서버로 올라가지 않습니다.

> 서버비가 0원이라는 건 우리 입장에선 마진율 99%의 악랄한 BM이지만,
> **유저 입장에선 "내 데이터가 절대 밖으로 새어나가지 않는다(Data Sovereignty)"는 가장 강력하고 압도적인 구매 이유**가 됩니다.

## 랜딩 페이지 추가 섹션: "Zero Data Leak"

### 섹션 타이틀

## 당신의 소스코드는 단 1바이트도 우리의 서버로 올라가지 않습니다.

**MUSU는 통제할 뿐, 훔쳐보지 않습니다.**

> AI에게 회사의 기밀 코드나 고객 DB를 넘겨주기 찝찝하십니까?
> 당연합니다. 클라우드 기반의 AI 툴들은 당신의 작업물을 서버로 퍼 나르기 바쁘니까요.
> MUSU는 다릅니다.
> **우리가 가져가는 건 당신의 결제용 이메일 계정 하나뿐입니다.**
> 당신이 짠 코드, 실행되는 파일, 연결된 MCP 데이터베이스의 내용물... 그 어느 것 하나 당신의 컴퓨터(하드디스크)를 떠나지 않습니다. 외부에서 HiveLink로 원격 접속할 때도, 데이터는 중간 서버를 거치지 않고 당신의 기기 간에만 P2P(QUIC)로 강력하게 암호화되어 직결됩니다.
> AI의 지능만 빌려 쓰십시오.
> 당신의 데이터는 영원히 당신의 로컬 PC 안에서만 숨 쉽니다.

### 팩트폭행: 왜 이 카피가 결제를 확정 짓는가

1. **엔터프라이즈급 설득력:** 회사에서 "나 커서 결제할래" 하면 보안팀이 컷(Cut)합니다. 하지만 "이건 데이터가 외부망으로 안 나가는 로컬 통제망이야"라고 하면 결제 기안이 통과됩니다. B2B 확장의 핵심 논리입니다.
2. **신뢰의 완성:** 앞서 우리가 유저에게 "니 설정 파일(MCP, Skill) 1초 만에 훔쳐올게!"라고 좀 '악랄하게(?)' 접근했잖아요? 이 보안 카피가 들어가는 순간, "아, 세팅은 편하게 다 긁어오지만, 진짜 중요한 내 데이터는 로컬에 박아두고 보호해 주는 '진짜 내 편'이구나"라는 절대적인 신뢰로 바뀝니다.

## 보안 백서 (Security Whitepaper) + 동네 아저씨 번역

### 1. 절대적 샌드박스: 임의 코드 실행(RCE) 원천 차단

* **쉘 인젝션의 완전한 멸망:** 터미널 명령어를 우회할 수 있는 `sh -c` 기반의 실행 경로를 아키텍처에서 영구적으로 제거했습니다.
* **구조화된 화이트리스트 (Allowlist):** 오직 사전에 승인된 구조화된 명령어(Structured Command)와 안전한 인자(Arguments)만을 통과시킵니다.
* **DLP (데이터 유출 방지) 결합 파일 시스템:** AI가 파일을 읽고 쓸 때는 반드시 `FileAccessEngine`을 거쳐야 하며, 디렉토리 탈출(Path Traversal) 시도는 즉시 차단되고 DLP 정책에 의해 시크릿 데이터 반환이 금지됩니다.

> 🍺 **[동네 아저씨 번역]**
> "야, AI가 맘대로 니 컴퓨터 포맷하면 어떡할래? 그래서 걔 손발 다 묶어놓고 우리가 허락한 숟가락질만 하게 만들었어. 몰래 남의 폴더 뒤지거나 헛짓거리 하려고 하면 바로 손모가지 날아가는 거지."

### 2. 암호학적 원격 통제망: HiveLink Mesh Auth

* **HMAC-SHA256 서명 교환:** 단순한 문자열 기반 인증을 폐기하고, 강력한 암호학적 피어(Peer) 인증을 도입했습니다.
* **Replay Attack(재전송 공격) 방어:** 모든 패킷에 1회성 난수(Nonce)와 타임스탬프(TTL) 검증을 강제하여, 탈취된 패킷을 이용한 악의적 재접근을 물리적으로 불가능하게 만듭니다.

> 🍺 **[동네 아저씨 번역]**
> "밖에서 집 컴터 접속할 때 누가 옆에서 몰래 비번 훔쳐봤다가 나중에 똑같이 문 두드리면 털리잖아? 그래서 1초마다 암구호 계속 바꾸게 해놨어. 어제 쓴 암구호 오늘 대면 바로 쌍욕 박고 셔터 내려버려."

### 3. Fail-Closed 아키텍처: "모르면, 일단 죽인다"

* **단일화된 시크릿 강제 (Hard-Fail):** 게이트웨이 인증키(`MUSU_SHARED_SECRET`)가 프로덕션 환경에 누락되어 있다면, 시스템은 불안정한 상태로 켜지는 대신 즉시 부팅을 거부(Startup Hard-Fail)합니다.
* **권한 누락 시 전면 차단 (Deny-by-Default):** 에이전트의 권한(Permission)이 명시적으로 승인되지 않은 경우, 기본적으로 '모든 권한 부여'가 아닌 '모든 접근 차단(Fail-Close)' 상태로 격리됩니다.

> 🍺 **[동네 아저씨 번역]**
> "뭔가 세팅이 찜찜하거나 비밀번호를 제대로 안 챙겨왔다? 그럼 '에이 일단 열어줄게'가 어딨어. 얄짤없이 장사 접고 퇴근하는 거야. 모르면 일단 닫고 보는 게 상책이지 안 그래?"

### 4. CI/CD 보안 자동화: 타협 없는 파이프라인

* **Docs-as-Code 정합성 검증:** 보안 문서에 명시된 정책과 실제 코드의 인증 로직이 일치하는지 CI 단계에서 스크립트(`scripts/check-security-consistency.sh`)로 자동 검증합니다.
* **엄격한 릴리즈 게이트:** 프로덕션 브랜치 배포 전, 의도치 않은 하드코딩 시크릿(취약한 DB 비밀번호 등)이나 인증 우회 경로가 없는지 강력한 보안 회귀 테스트가 의무적으로 실행됩니다.

> 🍺 **[동네 아저씨 번역]**
> "내가 개발자놈들 말만 믿고 어떻게 배포를 해? 기계 시켜서 얘네가 설명서대로 똑바로 짰는지, 코드에 이상한 구멍 안 파놨는지 매일매일 멱살 잡고 탈탈 터는 거야."

### 최종 결론 (Data Sovereignty)

**"당신의 데이터는 당신의 컴퓨터를 떠나지 않습니다."**

> 🍺 **[동네 아저씨 번역]**
> "어렵게 생각할 거 없어. 결론이 뭐냐고? 니가 짠 코드랑 회사 기밀, 내 서버로 한 글자도 안 가져간다고. 니네 집 안방에서 일어난 일은 평생 니네 집 안방에만 있는 거야. 쫄지 말고 그냥 써."

### 샷건 드립

> 🍺 **[동네 아저씨의 마지막 경고]**
> "원래는 이상한 짓 하는 AI나 해커놈들 쏴버리라고 서버에 진짜 샷건을 달아놓고 싶었는데, 그건 불법이라 내가 철창 간다더라? 그래서 아쉬운 대로 '접근 차단(BLOCK)' 버튼에 전기 충격기만 달아놨어. 허튼수작 부리면 연결된 패킷째로 튀겨버릴 거니까 얌전히 써."

## 아키텍처 마케팅 포인트 4가지

### 1. 궁극의 포지셔닝 슬로건: "AI proposes. MUSU enforces."

* **발견:** `README.md`에 적어두신 킬러 라인.
* **왜 중요한가:** "MUSU가 통제한다"라고만 길게 설명하지 말고, 이 짧은 한 문장이 MUSU의 정체성(AI Boundary Layer)을 완벽하게 정의.
* **마케팅 카피:**
> **"AI는 제안할 뿐입니다. 집행은 MUSU가 합니다."**
> AI가 코드를 짜고 시스템을 건드린다고요? 아닙니다. AI는 텍스트를 뱉을 뿐입니다. 그 코드가 안전한지, 내 의도(Intent)에 맞는지 검열하고 멱살 쥐고 실행시키는 건 오직 MUSU의 권한입니다.

### 2. 95% API 요금 삭감의 비밀: 'Holodeck 가상 쉘'

* **발견:** `p15-prime-system.md`의 Holodeck 파트. 100MB 로그를 AI한테 통째로 먹이면 133,000 토큰이 날아가지만, Holodeck에서 가상으로 `grep`, `awk`를 돌리면 6,000 토큰으로 **95%가 절감**.
* **마케팅 카피:**
> **"당신의 AI는 왜 그렇게 비싸고 멍청합니까?"**
> 로그 파일 하나 찾겠다고 10만 토큰씩 클로드 입에 쑤셔 넣고 계십니까? MUSU의 'Holodeck' 가상 쉘은 AI가 직접 `grep`과 `cat`을 쳐서 필요한 데이터만 파싱하게 만듭니다. 컨텍스트는 깃털처럼 가벼워지고, 당신의 API 요금 청구서는 95% 삭감됩니다.

### 3. AI의 금붕어 기억력 치료: 'Block Chain Chunking'

* **발견:** `block-chain-chunking.md`. 남들은 LangChain으로 의미도 없이 500토큰씩 문서를 썰어버릴 때, 함수의 선언부나 마크다운 헤더 등 **'의미 경계'**에서 블록을 나누고 부모-자식 체인으로 엮어버림.
* **마케팅 카피:**
> **"AI의 머릿속에 '의미의 족보'를 심어줍니다."**
> 타사 툴들은 당신의 코드를 500글자씩 토막 내서 AI에게 던져줍니다. 서론인지 결론인지도 모르죠. MUSU는 코드를 '의미 단위'로 자르고 블록체인처럼 계보를 연결합니다. "이 코드가 어디서 왔는지, 직전 미션에서 왜 실패했는지" AI가 완벽한 문맥(Context)을 이해하게 만드십시오.

### 4. 삽질 방지 시스템: Time Stone (Think → Simulate → Act)

* **발견:** `p15-prime-system.md`의 Time Stone과 Ouroboros 루프. AI가 짠 전략을 바로 실행하는 게 아니라, 샌드박스에서 여러 전략을 '시뮬레이션' 돌려보고 에러 점수를 매겨서 최적의 1개만 통과시킴.
* **마케팅 카피:**
> **"실수는 샌드박스 안에서만. 프로덕션에는 완벽한 결과만." (Mistakes don't ship.)**
> AI가 친 사고를 수습하느라 밤새운 적 있으십니까? MUSU는 AI의 코드를 당신의 파일에 바로 덮어쓰지 않습니다. 뒤에 마련된 가상의 시뮬레이션 룸(Time Stone)에서 먼저 돌려보고, 스스로 에러를 고치게 만듭니다. 오직 검증된 완벽한 결과물만 당신의 하드디스크에 기록됩니다.
