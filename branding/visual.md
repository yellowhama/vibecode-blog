## 소셜 에셋 (미완성 — 사람이 해야 하는 것)

### 프로필 사진
- 현재: 없음
- 필요: 사람 얼굴 또는 캐릭터 일러스트
- 개인 브랜드엔 얼굴이 가장 강력함
- 캐릭터 쓸 경우: MUSU Bee 스타일 (claymation 꿀벌)과 톤이 달라야 함 — vibecode는 MUSU 브랜드가 아님

### X 배너
- 현재: 없음
- 필요: 심플. 텍스트 최소.
- **안 되는 것**: 블로그 URL 크게 박기 = 광고판
- **되는 것**: 코드 에디터 캡처, 터미널 화면, 또는 그냥 색상 배경

### OG 이미지 템플릿
- 블로그 글 공유 시 자동 생성되는 이미지
- 현재: AstroPaper 기본값
- 필요: 브랜드 색상 + 글 제목 + 저자명
