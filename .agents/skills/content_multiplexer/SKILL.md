# Content Multiplexer

블로그 소스 하나를 Twitter thread plan, Video narration script, Short-form slide script 3채널로 동시 변환하는 스킬.

## 서브커맨드

| 커맨드 | 설명 |
|--------|------|
| `/multiply <blog-path>` | 소스 → 3채널 초안 생성 → 유저 리뷰 → 승인 시 파일 저장 |
