# Shorts Pipeline

블로그/트위터 소스를 TikTok, Instagram Reels, YouTube Shorts용 슬라이드 기반 숏폼 콘텐츠로 변환하는 3단계 파이프라인.

## 서브커맨드

| 커맨드 | 설명 |
|--------|------|
| `/shorts-plan <source-path>` | 소스 분석 → 5-8 슬라이드 시퀀스 설계 |
| `/shorts-draft` | 설계 기반 슬라이드 스크립트 JSON 생성 |
| `/shorts-check` | 브랜딩 + 숏폼 전용 규칙 검증 |

## 포맷

- 세로 9:16 비율
- 슬라이드 기반 (이미지+텍스트 오버레이)
- 15-60초 총 분량
- 첫 슬라이드 = 행동/감정 hook (1초 스크롤 정지)
