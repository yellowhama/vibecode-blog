# Branding Reviewer Skill

This skill allows the agent to review any content (blogs, tweets, generic copy) against the Vibecode Blog core branding rules.

## Process

1. Read `branding/BRAND.md` to understand who the author is and the golden Nike Rule.
2. Read `branding/voice.md` for specific style constraints.
3. Read `branding/narrative.md` to ensure the content reflects the 3-act structure and avoids pure explanation without narrative.
4. Provide a review pointing out any sentences or sections that violate the brand voice and suggest revisions.

## Resources
You must read and follow the instructions in these files:
- `branding/BRAND.md`
- `branding/voice.md`
- `branding/narrative.md`
