# ComfyUI Video Pipeline Skill

This skill guides the agent in orchestrating the creation of AI-generated video prompts specifically tailored for a **ComfyUI Text-to-Image (T2I) -> Image-to-Video (I2V) Pipeline**. The input is a structurally formatted Storyboard containing T2I and I2V shots (generated by the `video_storyboard_planner`), and the output is a **JSON Manifest Document** that can be plugged directly into the automated Codex CLI batch renderer (`comfy_batch_render.py`).

## Workflow Guidelines

1. **Review the Storyboard Input**: 
   - Identify all `[Shot X.Y - T2I]` and `[Shot X.Y - I2V]` tags and their estimated duration from the provided storyboard.

2. **Automated Batch Render Process & Pipeline Architecture**:
   - The automated closed-loop system operates on a dual-stage execution model to guarantee **Visual Consistency** and **Motion Stability**.
   - **Phase 1: Keyframe Generation (T2I + Conditioning)**: Due to the limitations of raw Text-to-Video models in maintaining strict character appearances (e.g., exact colors, textured clay), **pure T2V workflows are strictly prohibited for narrative shots.** Generate robust `T2I` base image keyframes containing **IP-Adapter/FaceID/Reference-Only conditioning nodes** fed by the `character_master_sheet.png` to lock the visual identity.
   - **Phase 2: Video Generation (I2V)**: The generated T2I base images are assigned to the `input_image` field in the shot manifest (setting the mode to `i2v`). The batch rendering script orchestrates the UI API to extrapolate the motion from the accurate keyframe.
   - **Prerequisite:** The target ComfyUI I2V workflow MUST be exported in **API format** (Save (API) in ComfyUI, NOT the standard UI JSON).
   - **Execution:** The videos are generated using `/scripts/run_batch_render.sh <manifest.json> <api_workflow.json> <bindings.json>`.

3. **Base Style Enforcement (MANDATORY)**:
   - Every **T2I/T2V** prompt MUST include the core aesthetic description to guarantee consistency across shots.
   - *Base Style Template:* `Minimalist stop-motion claymation, Aardman studio style. A highly textured clay figure in a vast, empty Off-White solid background. No room details, extremely simple minimalist environment, resembling a 3D whiteboard animation. Soft matte lighting.`
   - Ensure the character colors (e.g., `#2D1D19` cocoa brown hoodie, `#FFD166` Musu Yellow skin) are explicitly stated in T2I prompts.

4. **Anti-Hallucination Guardrails (MANDATORY)**:
   - Video models frequently hallucinate text and speech. EVERY single prompt (both T2I and I2V/T2V) MUST end with this exact string:
   - `CRITICAL: NO TEXT, NO LETTERS, NO SPEECH BUBBLES. The character is completely silent, mouth closed, no speaking, nonverbal, nonlingual.`

5. **Motion Generation (I2V / T2V)**:
   - If using a T2V (Text-to-Video) model like Wan 2.1 directly, describe the complete initial static scene and the specific motion that follows within a single prompt. Include camera motions (e.g., "Static camera", "Camera pushes in").
   - **Motion Bucket/Scale Instruction**: For each prompt, explicitly state the recommended Motion Intensity.
     - `Low`: Subtle movements like typing, blinking, or slow panning.
     - `High`: Slapstick comedy, objects falling fast, or shape-shifting/morphing.

## Output Constraints: The Shot Manifest (JSON)

Your final output must be a valid JSON file following the **Shot Manifest format (v2)**. This file will be parsed by `comfy_batch_render.py`.

**Manifest JSON Structure Example:**
```json
{
  "project_id": "phase1_act1",
  "style_lock": "skeptical claymation + off-white background + no text overlay",
  "delivery_target": "16:9, 720p, scene-based clips",
  "model_policy": {
    "primary": "wan2.1_t2v_1.3B_fp16.safetensors"
  },
  "shots": [
    {
      "shot_id": "S01_01",
      "scene": "Scene1",
      "purpose": "character at desk before chaos",
      "prompt_positive": "[Insert fully constructed prompt here, including base style and anti-hallucination guardrails]",
      "prompt_negative": "text, subtitles, watermark, logo, speech bubble, extra limbs",
      "duration_sec": 8,
      "aspect_ratio": "16:9",
      "resolution": "1280x720",
      "seed": 1201001,
      "model": "wan2.1_t2v_1.3B_fp16.safetensors",
      "mode": "t2v",
      "input_image": null,
      "output_name": "S01_01.webp"
    }
  ]
}
```
