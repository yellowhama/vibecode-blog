# 020  RAG

# 자료 정리 지옥에서 탈출하기 - RAG로 3분 만에 필요한 정보 찾는 법

## TL;DR

- **문제**: 9세기 유럽 자료 300페이지. 필요한 건 3줄. 찾는 데 37분
- **해결**: RAG 시스템 = 질문하면 관련 자료 + 출처 자동으로 찾아줌
- **효과**: 리서치 시간 37분 → 3분 (91% 감소)
- **핵심**: Claude Code가 다 만들어줌. 나는 "찾아줘"만 하면 됨

일요일 밤이다. 내일까지 9세기 카롤링거 왕조 군사 조직에 대한 글을 써야 한다.

이 안 어딘가에 "카롤링거 왕조의 기병 중심 전술 도입" 관련 내용이 있다. 분명히 읽었던 기억이 난다. 어디였더라?

첫 번째 PDF 열었다. Ctrl+F. "기병".

147개 결과.

하나씩 클릭한다.

"비잔티움 제국의 기병..." 아니야.
"훈족의 기병 전술..." 이것도 아니고.

30분이 지났다.

드디어 찾았다. 78페이지.

복사. 메모장에 붙여넣기. 출처 적기.

## 전통적 방식 vs RAG

**기존 방식 (37분)**:
PDF 열고 → Ctrl+F 검색 → 147개 결과 클릭 → 관련 부분 찾아 읽기 → 복사 → 출처 확인

**RAG 방식 (3분)**:
터미널 열고 → "카롤링거 기병 전술" 입력 → 관련 자료 3개 + 출처 자동 제공 → 읽기

**차이: 34분 절약 (91% 감소)**

## RAG의 진짜 역할 - AI가 글을 쓰는 게 아니다

명확히 하자.

**RAG는 글을 대신 써주지 않는다.**

RAG의 역할: 자료 찾기 + 정리 + 출처 제공

내 역할: 읽기 + 판단 + 해석 + 글쓰기

RAG는 재료를 주는 사서고, 나는 그걸로 요리하는 셰프다.

---

## 한계도 있다

### 자료에 없는 건 못 찾는다

당연하지만, 내 자료에 없는 내용은 찾아줄 수 없다.

환각(Hallucination)은 없다. 없으면 없다고 한다.

### 여러 문서 종합은 내가 한다

RAG는 관련 청크 3-5개를 따로따로 준다.

이걸 어떻게 엮을지는 내가 결정한다.

### 태그 정확도는 70-80%

자동 태깅이 완벽하진 않다.

샘플 확인하고, 규칙 수정하고, 다시 돌렸다. 2-3번 반복하니까 쓸만해졌다.
