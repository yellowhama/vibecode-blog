# 015

# AI가 만든 파일 지옥, 어떻게 정리할까? – Git으로 게임처럼 '세이브'하는 법

**TL;DR**

- 밤새 코딩했는데 아침에 보니 파일 30개. 어느 게 돌아가는 버전인지 모른다.
- Git은 게임의 세이브 포인트다. 망가뜨려도 3초면 복구된다.
- Claude Code로 빠르게 만들수록, Git 없으면 더 빨리 망한다.

---

## 월요일 아침의 공포

월요일 아침이다. 커피 한잔 들고 컴퓨터 켰다.

금요일 밤까지만 해도 잘 돌아가던 게임이었다. 주말 동안 전술 시스템 추가하고, 선수 교체 기능 넣고, UI도 좀 만졌다. Claude Code한테 시키니까 진짜 빨랐다.

폴더 열었다.

파일이 30개다.

`game.godotgame_backup.godotgame_전술추가.godotgame_최종.godotgame_최종_진짜.godotgame_최종_진짜_마지막.godot`

그 밑으로 숫자가 7까지 붙어있다.

어느 게 돌아가는 버전이지?

하나 열어봤다. 실행했다. 화면이 하얗게 뜬다.

다음 파일. 전술 버튼이 안 보인다.

또 다음 파일. 에러 메시지만 뜬다.

30분이 지났다.

드디어 하나 찾았다. `game_전술추가.godot`. 돌아간다!

근데 파일 날짜를 보니 목요일이다.

오늘 월요일인데.

**3일 동안 작업한 게 다 어디 갔지?**

---

## AI가 빠를수록 파일은 더 많아진다

혼자 코딩할 땐 괜찮았다. 하루에 파일 2-3개 정도 생겼다. 뭘 고쳤는지 대충 기억났다.

Claude Code랑 일하기 시작하면서 달라졌다.

"이거 해줘" 하면 5초 만에 파일 3개가 수정된다.
"저것도" 하면 10초 뒤 파일 5개가 더 생긴다.

하루에 파일이 20개씩 쌓인다.

빨라진 건 좋은데, 뭐가 뭔지 모르겠다.

Rust 파일도 마찬가지다. `main.rs`, `main_old.rs`, `main_백업.rs`, `main_수정.rs`, `main_수정2.rs`... 어느 게 컴파일 되는 버전인지 기억이 안 난다.

**속도의 대가다.**

---

## "게임 세이브처럼 하면 안 돼?"

Claude한테 물었다.

"Git이 뭐야? 게임으로 설명해줘"

답이 왔다.

*"다크소울의 모닥불이에요. 보스 잡으러 가기 전에 세이브하잖아요. 죽으면 그 지점으로 돌아가고. Git도 똑같아요. 코드 수정하고 세이브 누르면 그 시점으로 언제든 돌아갈 수 있어요."*

아.

이해됐다.

그럼 파일명에 `최종`, `진짜`, `마지막` 이런 거 안 붙여도 되는 거네?

---

## 5분 만에 세이브 시스템 설치

터미널 열고 한 줄만 쳤다.

파일명은 그대로 `game.godot` 하나.

근데 이제 Git이 모든 변경사항을 기록한다.

전술 시스템 추가했다. 세이브 한 번.
포메이션 수정했다. 세이브 또 한 번.

**파일은 하나. 세이브는 무한대.**

---

## 망가뜨려도 3초 복구

포메이션 코드 고치다가 게임이 아예 안 돌아간다.

예전 같으면 백업 파일 30개를 하나씩 열어봤을 거다. 1시간은 걸렸다.

지금?

세이브 목록 봤다.

"포메이션 수정" (방금)
"전술 시스템 추가" (1시간 전)
"프로젝트 시작" (아침)

1시간 전 세이브로 돌아갔다.

**3초.**

게임 실행했다. 된다.

포메이션 수정한 거 없었던 일로 됐다.

---

## 뭘 고쳤는지도 바로 보인다

어디서 실수했는지 찾는 것도 쉬워졌다.

이전엔 파일 두 개 열어놓고 눈으로 비교했다.

이제는 Git이 보여준다.

"아, 여기 이 줄에서 실수했구나."

빨간색으로 지워진 거, 초록색으로 추가된 거. 한눈에 보인다.

---

## 일주일 후

프로젝트 폴더가 깔끔하다.

파일 하나. `game.godot`

근데 실제로는 세이브 포인트가 127개다.

언제든 되돌릴 수 있다. 뭘 언제 고쳤는지 전부 기록돼 있다.

목록 봤다.

"선수 스탯 밸런스 조정"
"전술 변경 UI 개선"
"포메이션 5개 추가"
"경기 시뮬레이션 속도 개선"
"버그 수정: 선수 중복 선발"

**타임머신이 생긴 기분이다.**

---

## Claude Code + Git = 안전한 폭주

"전술 시스템 개선해줘"

Claude Code가 파일 10개를 수정한다.

세이브 누른다.

마음에 안 들면?

바로 전 세이브로 돌아간다.

**Claude Code는 속도다. Git은 안전망이다.**

둘이 만나면 완전체가 된다.

---

## 처음엔 대충 적었다

세이브할 때 메모 남기는 거.

처음엔 "수정", "업데이트", "최종" 이렇게만 적었다.

일주일 뒤 보니까 뭘 수정했는지 하나도 모르겠다.

이제는 이렇게 적는다.

"전술 시스템: 4-3-3 포메이션 추가"
"버그 수정: 선수 교체 시 충돌"
"UI 개선: 전술 버튼 크기 조정"

**미래의 나한테 보내는 쪽지다.**

---

## 결론: 파일명 지옥에서 탈출했다

더 이상 이런 거 안 한다.

파일명에 `최종_진짜_마지막_v7` 붙이기.
어느 파일이 돌아가는지 모르기.
3일 작업 날아가기.

이제는 이렇다.

파일 하나만 있다.
모든 버전이 기록된다.
언제든 되돌릴 수 있다.

**Git은 선택이 아니다. 필수다.**

특히 AI랑 같이 일한다면.

Claude Code가 빠를수록, Git 없으면 더 빨리 망한다.

세이브 시스템 없이 다크소울 하는 거랑 똑같다.

보스 앞에서 죽으면 처음부터 다시다.

**그거 하기 싫으면 Git 깔아라.**
