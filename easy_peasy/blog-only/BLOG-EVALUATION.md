### 번역 워크플로우

```
[Phase 1] 한국어 원문 최종 정리

```

│   └── ...

**URL 구조**: `/ko/ai-gold-rush` + `/en/ai-gold-rush`
- `prefixDefaultLocale: true` → 둘 다 명시적 locale prefix
- hreflang 태그로 상호 연결
- RSS: `/ko/rss.xml` + `/en/rss.xml` 별도
- sitemap: Astro `@astrojs/sitemap` 자동 locale-aware 생성

## 핵심 결론

1. **책 기준 → 블로그 기준으로 바꾸면 순위가 바뀐다.** 책에서 빠진 027이 블로그에서는 S급 킬러.
2. **시의성 콘텐츠(032, 033, 029, 044)는 블로그에서도 가치가 낮다.** 아카이브 처리.
3. **영어 번역 ROI가 가장 높은 건 T1 8편.** 한국 기술 블로거 영어 시장이 블루오션.
4. **번역은 "번역"이 아니라 "영어 원문 재창작" 수준으로.** 키워드 리서치 별도, 제목 별도, 문화 맥락 별도.
5. **Astro i18n은 네이티브 지원.** `/ko/` + `/en/` + hreflang + 별도 RSS로 깔끔하게 분리.
