## 반복 발견 패턴 (Cross-Cutting Issues)

### 1. 미검증 통계 습관
많은 글에서 "생산성 5배", "에러 90% 감소", "3시간→30분" 같은 수치를 **자기 경험 1건**으로 일반화.
→ **수정**: "내 경우에는" 또는 "약 X배 개선을 경험했다"로 한정

### 2. 미공개 자사 제품 레퍼런스
#050 (Spec Kit), #053 (Rust 스캐폴딩), #057 (.vibe/cache), #058 (P2P 멀티디바이스) 등에서 MUSU/HiveLink/Vibe PM을 언급하지만 자사 제품임을 밝히지 않음.
→ **수정**: "이건 내가 만들고 있는 프로젝트인데..." 등 간단한 공시 추가

### 3. Claude Code 진화 미반영
전체 시리즈가 Claude Code v1~초기 v2 기준으로 작성. v2.1의 핵심 기능(서브에이전트, Hooks, Skills, MCP, Chrome, Planning Mode 개선)이 거의 반영 안 됨.
→ **수정**: #002(설치), #031(매뉴얼), #017(서브에이전트) 최소 3편 업데이트 필수

### 4. 출처 미기재
"연구에 따르면", "조사에 의하면" 등으로 인용하면서 구체적 출처(저자, 논문명, URL)를 빠뜨린 경우 다수.
→ **수정**: 각 통계/인용에 최소 출처명+연도 추가

### 5. 045 ↔ 046 주제 중복
두 글 모두 "프롬프트→컨텍스트" 패러다임 전환을 다룸. 각도가 약간 다르지만 병합 또는 차별화 강화 필요.
