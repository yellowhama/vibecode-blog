# Design Blocks (RAG)

목표: “예쁜 디자인”이 아니라, 항상 같은 블록으로 조립되는 와이어프레임을 만든다.

## 블록 5개(고정)

1. Hero: 이미지 1 + 헤드라인 + 불릿 3 + CTA
2. USP: 카드 3개(아이콘/제목/설명)
3. Proof: 표 1개 또는 카드 3개(근거만)
4. FAQ: 아코디언 5개
5. CTA: 요약 + 버튼 + 필수 고지

## 모바일 우선 규칙

- 한 섹션은 스크롤 1~2번 안에 끝내기(텍스트 폭주 금지)
- 불릿은 3개까지만
- 버튼은 1개만 진하게(결정 피로 줄이기)

## 안전한 레이아웃 규칙

- 섹션 간 여백은 넉넉하게(답답함 방지)
- 이미지 슬롯이 없으면: 아이콘/표로 대체
