# Pricing Rules (RAG)

목표: 가격/옵션/할인을 “안전하게” 보여준다. (오해/컴플레인 방지)

## 가격 표시 기본

- 가격은 숨기지 않는다(결정 피로 줄이기)
- 통화/단위는 명확히(원, 개, kg 등)
- 옵션이 있으면 “시작가”인지 “단일가”인지 표시

## 할인/프로모션 안전 규칙

- 근거 없는 “할인/최저가/역대급” 금지
- 기간/조건이 있으면 반드시 같이 쓴다(예: “3/1~3/7, 쿠폰 적용 시”)
- “무료”는 조건이 있으면 조건을 먼저 쓴다(예: “3만원 이상 무료배송”)

## 가격 정보가 없으면(SSOT에 가격 정보가 비어있음)

- 가격을 **만들어내지 않는다**.
- 아래처럼 `TODO`로 남기고, 질문으로 돌린다.
  - `가격: TODO (판매처/마켓 확정 후 기입)`
  - `옵션별 가격: TODO (옵션/추가금 확인 필요)`
- “특가/세일/최저가” 같은 단어는 가격 정보가 확정되기 전엔 쓰지 않는다.

## 세트/옵션 표현(추천 패턴)

- “옵션: A / B / C”처럼 단순한 표기
- 세트는 구성품을 같이 적기(오해 방지)

## 카피 금지 힌트(가격 파트)

- “무조건 이득”, “반드시 싸다” 같은 절대 표현 금지
- “지금 안 사면 손해” 같은 과한 압박 표현은 최소화
