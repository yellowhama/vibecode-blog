# Brand Voice (RAG)

목표: 상세페이지 초안이 “AI 티”가 나지 않게, 톤을 고정한다.

## 기본 톤

- 친절하지만 과장하지 않는다
- 짧고 구체적으로 쓴다
- “우리 제품이 최고” 대신 “이 제품은 이런 상황에서 도움이 된다”로 말한다

## 금지 표현(대표)

- 100% 보장 / 무조건 / 최고 / 완치 / 즉시 효과
- 근거 없는 수치, 근거 없는 비교

## 허용되는 문장 패턴(추천)

1. 한 줄 결론 -> 이유 1개 -> 예시 1개
2. “이런 분에게 좋아요” -> “이럴 때 편해요”
3. “문제(불편)” -> “해결(이 제품)” -> “근거(팩트/스펙/라벨)”

## 섹션별 톤 주의

- Hero: 감탄사 금지, 한 문장만 강하게
- Proof: 감정 표현 금지, 근거만
- FAQ: 딱딱하지 않게, 짧게 답하기
