# Section Playbook (RAG)

목표: “섹션을 어떻게 짜야 하는지”를 AI가 항상 같은 방식으로 만들게 한다.

## Hero

- 목적: 한 줄 약속(왜 사야 하는지)
- 구성: 제품 사진 1 + 한 줄 + 불릿 3 + CTA 1
- 길이 제한: 헤드라인 18자 내, 불릿 14자 내(모바일 기준)

## USP (장점)

- 목적: “좋은 점”을 3개로 압축
- 구성: 카드 3개(제목 1줄 + 설명 1~2줄)
- 주의: 장점이 “감정”이 아니라 “관찰 가능한 내용”이어야 함

## Proof (근거)

- 목적: 믿게 만들기
- 구성: 스펙/수치/인증/후기 중 “근거”만
- 주의: 근거가 없으면 빈칸(TODO)로 남기기

## FAQ

- 목적: 불안/반문 제거
- 구성: 질문 5개(짧게)
- 예: 배송, 교환/환불, 보관/사용, 호환, AS

## CTA

- 목적: 구매 행동 유도
- 구성: 요약 3줄 + 버튼 1개 + 필수 고지(짧게)
