# QA Rules (RAG)

목표: 자동화가 “빠르게”가 아니라 “안전하게”도 되게 만든다.

## 근거 규칙

- “수치/효과/인증”은 근거가 없으면 쓰지 않는다
- 근거가 없으면 `TODO`로 남기고 질문으로 돌린다

## 필수 고지(예시)

- 배송/교환/환불
- 주의사항(식품/전자/자재 등 카테고리별)
- AS/보증(전자제품)

## 과장 탐지 힌트

- “최고/무조건/완벽/100%” 같은 단어는 삭제
- 비교 표현(타사 대비)은 근거가 없으면 삭제

## 중복/장황 탐지

- 같은 말을 Hero/USP/CTA에서 반복하면 삭제
- 한 섹션이 길어지면 불릿 3개로 줄이기
