## 2. 첫 100명 전략

### Phase 1: 개인 네트워크 (Day 1-14, 목표: 30-50)
- 500+ 커넥션에 개인 메시지: 5-10% 전환
- 모든 소셜 프로필에 런치 공지

### Phase 2: 커뮤니티 시딩 (Day 14-60, 목표: 50-100)
- Reddit: r/ChatGPT, r/ClaudeAI, r/cursor에 도움되는 콘텐츠 (링크는 프로필에만)
- Hacker News: "Show HN" 포맷, 절대 업보트 요청 금지
- Dev.to / Hashnode / Medium: 크로스포스트 + canonical URL
- Discord/Slack: 커뮤니티에서 몇 주간 가치 제공 후 프로모션

### Phase 3: 리드 마그넷 (Week 3-8)
추천 리드 마그넷:
- "Claude 프롬프트 엔지니어링 치트시트" (1-2페이지 PDF)
- "Cursor 파워유저 가이드" (체크리스트)
- "AI 코딩 스택 비교 매트릭스"
- "50개 프로덕션 AI 프롬프트"

### Phase 4: Twitter/X 스레드 퍼널 (지속)
- 주 1-2개 고품질 스레드 + 매일 트윗
- 모든 스레드 끝에 CTA: "매주 이런 딥다이브를 뉴스레터로 공유합니다"
- X 바이오에 뉴스레터 링크 — #1 전환 경로

## 3. 100→1,000 스케일링

### 뉴스레터 크로스프로모션 (최고 ROI 무료 전략)
- 비슷한 규모 AI/dev 뉴스레터와 상호 추천
- SparkLoop Partner Network 합류
- Beehiiv Boosts
- Substack Notes 활발 참여

### 게스트 활동
- 팟캐스트 출연: 2-3회 → 100-300 가입/회
- 게스트 포스트: 50-100 가입/편
- 확립된 바이브코딩 보이스와 공동 콘텐츠 제작

### SEO 트래픽 퍼널
- 모든 뉴스레터를 블로그 포스트로도 발행
- 롱테일 키워드: "how to use Claude for [specific task]"
- 10-15개 포스트 최소 필요 → SEO 결과 3-6개월 후
- 24+ 포스트 = 30% 트래픽↑, 50+ = 77%↑

### Product Hunt 런치
- Tom Orbach: PH #1에서 5,600명 신규 구독자
- 바이브코더용 무료 도구/리소스 런치

## 5. 성장 루프

### 뉴스레터 플라이휠
```
좋은 콘텐츠 작성
  → 소셜 공유 (Twitter 스레드, LinkedIn)
    → 새 구독자 발견
      → 일부 구독자가 네트워크에 공유
        → 더 많은 구독자
          → 소셜 프루프 증가
            → 가입 전환율↑
              → 좋은 콘텐츠 작성 (반복)
```

### 레퍼럴 프로그램
| 추천 수 | 보상 |
|---------|------|
| 1-3 | 독점 콘텐츠 / 프라이빗 커뮤니티 |
| 5 | 디지털 제품 (치트시트) |
| 10 | 프리미엄 가이드/코스 |
| 25+ | 피지컬 굿즈 |

Morning Brew: 레퍼럴 + 스마트 디자인으로 대학 사이드프로젝트 → $75M 미디어 컴퍼니

## 7. 런치 전략

### Pre-Launch (2-4주 전)
1. "Coming Soon" 랜딩 페이지 + 이메일 캡처
2. 500+ 커넥션 DM → 50-100 프리런치 가입 목표
3. 3-5개 글 미리 준비
4. 리드 마그넷 제작
5. 신디케이션 플랫폼 프로필 셋업
6. 커뮤니티 합류 + 가치 제공 (프로모션 X)

### Launch Week
- Day 1: 베스트 글 발행 + 프리런치 리스트에 발송
- Day 2: Dev.to, Hashnode 크로스포스트
- Day 3: Hacker News 제출
- Day 4: Reddit 공유
- Day 5: 두 번째 글 발행
- Day 7: 첫 공식 뉴스레터

### 핵심 원칙
1. 일관성 > 완벽함 — 매주 발송, 예외 없음
2. 하나의 포맷, 하나의 길이, 주 1회로 시작
3. 80/20 — 80% 순수 가치, 20% 자기 홍보
4. 배포에 창작만큼 시간 투자 (50/50)
5. 작동하는 채널에 집중, 안 되는 건 드롭
6. Build in Public — 성장 숫자, 교훈, 어려움 공유 → 이것 자체가 콘텐츠
