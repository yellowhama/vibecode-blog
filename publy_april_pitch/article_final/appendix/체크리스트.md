# 검수 체크리스트

AI가 만든 초안을 넘기기 전에, 이 5가지만 확인합니다.

---

## 1. 근거 없는 말이 있는가?

"당도 13 brix", "업계 최초", "타사 대비 30% 저렴"

이런 문장이 있으면 근거를 찾습니다.
근거가 없으면 지웁니다.

**걸리면**: 문장을 지우거나, `TODO: 근거 확인 필요`로 바꿉니다.

---

## 2. 금지 표현이 있는가?

아래 표현은 상세페이지에 쓰면 안 됩니다.

| 금지 | 이유 |
|------|------|
| 100% 보장 | 증명 불가 |
| 무조건 | 조건 없는 약속은 위험 |
| 최고 / 최상 | 비교 근거 없음 |
| 완치 / 즉시 효과 | 의료/건강 과장 |
| 업계 최초 | 검증 불가 |
| ~보다 좋다 | 비교 근거 없으면 삭제 |

**걸리면**: 해당 문장을 사실 기반으로 바꿉니다.
- "최고의 사과" → "경북 부사 사과입니다"
- "무조건 만족" → "파손 시 100% 재발송"

---

## 3. 필수 고지가 빠졌는가?

카테고리별로 반드시 들어가야 하는 정보:

| 카테고리 | 필수 고지 |
|---------|----------|
| 공통 | 배송/교환/환불 안내 |
| 식품 | 원산지, 유통기한, 보관법, 알레르기 |
| 전자제품 | KC 인증, AS/보증, 전원 사양 |
| 화장품 | 전성분, 사용기한, 주의사항 |

**걸리면**: 빠진 항목을 `TODO: [항목명] 확인 후 추가`로 넣습니다.

---

## 4. 같은 말을 반복하고 있는가?

헤드라인에서 한 말을 본문에서 또 하고, 마무리에서 또 합니다.
한 번이면 됩니다.

**걸리면**: 가장 강한 위치에 한 번만 남기고, 나머지는 지웁니다.

---

## 5. 문장이 너무 긴가?

한 문장이 40자를 넘기면 읽기 어렵습니다.
특히 모바일에서.

**걸리면**: 마침표를 넣어서 두 문장으로 나눕니다.

---

## TODO 패턴 (모를 때 쓰는 표현)

정보가 없을 때, 거짓을 쓰는 대신 아래 패턴을 씁니다.

| 상황 | 쓰는 표현 |
|------|----------|
| 가격 모름 | `가격: TODO (판매처 확인 필요)` |
| 배송 모름 | `배송: TODO (판매처 정책 확인 후 입력)` |
| 수치 근거 없음 | `당도: (근거 필요)` |
| 인증 미확인 | `인증: TODO (라벨/서류 확인)` |
| 사진 없음 | `[사진 필요: 정면샷]` |

빈칸이 거짓보다 낫습니다.
