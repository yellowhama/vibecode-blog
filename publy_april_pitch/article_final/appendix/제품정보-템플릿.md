# 제품 정보 한 장 (설계도)

이 한 장이 공장의 설계도입니다.
아는 건 적고, 모르는 건 비워둡니다.

---

## 작성 규칙

1. **사실**만 적는다 — 라벨, 스펙표, 확인된 정보만
2. **추정**은 따로 적는다 — "아마 ~일 것 같다"는 사실과 섞지 않는다
3. **모르면 비운다** — 빈칸이 거짓보다 낫다
4. **질문**은 맨 아래에 — 확인해야 할 것을 모아둔다

---

## 예시: 사과 (채운 것)

### 제품 사실

| 항목 | 내용 |
|------|------|
| 상품명 | 부사 사과 |
| 카테고리 | 과일 |
| 한 줄 설명 | 먹는 생과일 |
| 옵션/종류 | 2kg(10과) 1박스 |
| 크기 | 손바닥 크기(대략) |
| 무게 | 1개 약 200g (총 2kg) |
| 구성품 | 사과 10과 |
| 원산지 | 경북 (라벨 기준) |
| 포장 표기 | (라벨 사진으로 확인) |

### 사용 사실

| 항목 | 내용 |
|------|------|
| 사용법 | 세척 후 섭취 |
| 누가 쓰나 | 가정용 간식, 선물용 |
| 어디서 쓰나 | 가정 |

### 근거/증명

| 항목 | 내용 |
|------|------|
| 수치 | (없음 — 당도 등은 근거 확인 후 작성) |
| 인증 | (없음) |
| 후기 | (없음) |

### 판매 정보

| 항목 | 내용 |
|------|------|
| 가격 | 12,900원 |
| 배송 | 산지 직송, 상온택배 2~3일 |
| 교환/환불 | 파손 시 100% 재발송 |
| AS/보증 | 해당 없음 (식품) |
| 문의처 | 판매처 문의 |

### 브랜드 규칙

| 항목 | 내용 |
|------|------|
| 톤 | 친절/단정 |
| 금지 표현 | "100% 보장", "무조건", "최고" |
| 주의 | 근거 없는 당도/효능 표현 금지 |

### 추정 (아직 확인 안 됨)

| 항목 | 내용 |
|------|------|
| 타겟 추정 | 30~40대 가정, 명절 선물 |
| 포지셔닝 아이디어 | 신선함 / 간편한 간식 / 선물용 |

### 질문 (확인 필요)

- 품종이 정확히 뭔가? (부사? 홍로?)
- 당도 기준이 있나? 선별 기준은?
- 포장에 뭐라고 적혀 있나? (사진 필요)
- 유통기한 또는 보관 방법은?
- 1박스 외에 다른 구성이 있나?
