## 1. 근본적 접근 차이

### 우리: "공장을 짓는다"
- 핵심 질문: "매번 처음부터 하지 않으려면?"
- 재료 한 장 + 지시서 + 매뉴얼 = 시스템
- 상품이 바뀌면 재료만 교체, 공장은 유지
- 사람이 모르는 건 **비워두고**, AI가 **질문**으로 채움

### uxjoseph: "팀을 굴린다"
- 핵심 질문: "상세페이지 제작비 100~500만원을 줄이려면?"
- 5개 에이전트가 순차 실행 → 완성된 이미지 출력
- 한 번 실행에 **완성품**을 목표로 함

## 2. 우리가 더 강한 부분

| 포인트 | 설명 |
|--------|------|
| **반복 루프** | 1차→질문→답변→2차 재실행. 매번 나아진다는 것을 실제 사과 예시로 증명 |
| **안전장치** | TODO 시스템, 금지 표현 자동 검수, 근거 없는 수치 차단 — uxjoseph에는 없음 |
| **비개발자 접근성** | Python/API 없이 Claude Code만으로 시작 가능 |
| **매뉴얼 시스템** | 톤앤매너, 섹션 규칙, 정책 등을 파일로 고정 → 담당자 교체에도 일관성 유지 |
| **사실/추정/질문 분리** | 입력 단계에서 정보 품질을 통제하는 구조 |
| **스토리텔링** | "사과 한 박스"에서 시작하는 공감형 서사 |

## 4. 출력물 비교

```
우리 글의 출력물 (텍스트 11개)     uxjoseph 출력물 (이미지 13개)
────────────────────────          ────────────────────────
1. 입력 점검                       1. Hero 이미지 (800px)
2. 품질 올리는 질문 ← 핵심!        2. Pain 이미지 (600px)
2b. 디자인 리서치 ← 신규!          3. Problem 이미지 (500px)
3. 섹션 기획                       4. Story 이미지 (700px)
4. 카피 초안 (2벌)                 5. Solution 이미지 (400px)
5. 블록 배치                       6. How It Works 이미지 (600px)
6. 색상                            7. Social Proof 이미지 (800px)
7. 이미지 지시                     8. Authority 이미지 (500px)
8. 촬영 목록                       9. Benefits 이미지 (700px)
9. 검수 리포트 ← 안전장치          10. Risk Removal 이미지 (500px)
10. 실행 요약                      11. Comparison 이미지 (400px)
                                   12. Target Filter 이미지 (400px)
                                   13. Final CTA 이미지 (600px)
```

**우리:** 기획~검수까지의 프로세스 문서 → 디자이너/실무자가 이걸 보고 실제 제작
**uxjoseph:** Gemini가 최종 이미지를 직접 생성 → 바로 업로드 가능

## 5. 파이프라인 위치

두 접근이 사실상 **파이프라인의 다른 단계**를 커버한다:

```
[우리 글 영역]                        [uxjoseph 영역]
정보 수집 → 검증 → 카피 → 검수    →    디자인 → 이미지 생성 → 합본
        ↑ 반복 루프 ↑                        ↑ 한 번에 출력 ↑
```

우리는 전반부(기획~검수)만 있고, 후반부(디자인~최종 이미지)가 없다.

## 6. 결론

| | 우리 글 | uxjoseph |
|--|---------|----------|
| **강점** | 프로세스, 안전장치, 반복 개선, 접근성 | 시각적 결과물, 구현체, 디자인 시스템 |
| **약점** | 최종 이미지가 없다 | 안전장치/반복 루프가 없다 |
| **포지션** | "어떻게 만들 것인가" (방법론) | "지금 바로 만든다" (실행) |

**핵심 차별점:**
"AI가 만들어주는 게 아니라, AI가 뭘 채워야 하는지 알려주는 거다" — 이 관점은 uxjoseph 레포에 전혀 없다.

**기회:**
우리 전반부(프로세스/안전장치) + 후반부(시각적 결과물)를 합치면,
uxjoseph보다 완성도 높은 end-to-end 시스템이 된다.
