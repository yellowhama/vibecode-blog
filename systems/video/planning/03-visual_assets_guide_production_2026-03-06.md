# Visual Assets Guide for Production QA (2026-03-06)

이 문서는 `evaluate_renders.py` 운영용 완화 프로파일이다.
목적은 "현재 기준선 렌더가 실제로 납품 불가인지"와 "스타일이 다소 흔들리지만 운영상 통과 가능한지"를 분리하는 것이다.

## 1. 평가 목적
- strict concept guide와 달리, production QA는 `치명적 시각 실패`를 우선 차단한다.
- 캐릭터/소품/질감이 100% 동일하지 않아도, 클레이메이션 세계관과 샷 목적이 유지되면 PASS 가능하다.
- 현재 baseline render는 prompt/모델 특성상 질감과 얼굴 디테일이 조금 흔들릴 수 있으므로 이를 부분 허용한다.

## 2. PASS 핵심 조건
- 전체 인상은 `찰흙/클레이메이션`으로 읽혀야 한다.
- 캐릭터는 둥글고 뭉툭한 실루엣이어야 하며, 과도한 사실적 인체 비율이면 안 된다.
- 메인 캐릭터의 노란 얼굴과 브라운 후드 조합이 유지되어야 한다.
- 배경은 단순하고 산만하지 않아야 하며, off-white 또는 유사한 미니멀 배경은 허용한다.
- 조명은 부드럽고 스튜디오형이어야 한다. 극단적 네온, 야간, 하드 콘트라스트는 지양한다.
- 샷의 목적(`purpose`)과 주요 액션은 프레임만 봐도 대체로 읽혀야 한다.
- 손, 눈, 얼굴, 소품이 심각하게 깨지지 않아야 한다.

## 3. 부분 허용 범위
- 지문/거친 질감이 약해져도 전체가 완전히 플라스틱/실사처럼 보이지 않으면 허용 가능
- 눈 간격, 코 크기, 입 모양이 조금 달라도 동일 캐릭터로 읽히면 허용 가능
- 소품 디테일이 단순화되어도 장면 의미 전달에 문제가 없으면 허용 가능
- 배경 톤이 off-white에서 약간 벗어나도 클린한 세트 느낌이면 허용 가능

## 4. 즉시 FAIL 조건
- 화면 안에 의도되지 않은 텍스트, 워터마크, 자막, 말풍선, 로고가 보임
- 얼굴 붕괴, 눈/손/팔다리 추가 생성, 심각한 해부학 오류
- 캐릭터 정체성이 바뀔 정도의 색상/형태 이탈
- 실사 피부, 유광 플라스틱, 금속성 표면처럼 클레이메이션 세계관이 무너짐
- 배경이 복잡한 실사 공간처럼 변해 장면 의미를 흐림
- 샷 목적과 무관한 물체/생물이 강하게 끼어듦
- 검은 화면, 노이즈 붕괴, 프레임 정지, 심한 압축 손상

## 5. 점수 운영 가이드
- `70+`: production PASS 후보
- `60-69`: review required에 가깝지만, evaluator는 명확히 PASS/FAIL 중 하나를 선택해야 함
- `59 이하`: FAIL
- 점수보다 `failed_metrics`와 치명 결함 유무를 더 중시한다

## 6. evaluator 지침
- strict art bible과의 미세 불일치보다 `영상 한편으로 이어졌을 때 시청자가 거슬릴 수준인지`를 우선 판단한다.
- "질감이 더 거칠었으면 좋겠다" 수준은 단독 FAIL 사유로 과대평가하지 않는다.
- 반대로, 텍스트/워터마크/해부학 붕괴/캐릭터 교체는 즉시 FAIL로 처리한다.
