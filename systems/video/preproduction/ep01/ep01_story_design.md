# EP01 스토리 설계 — "그냥 만들면 되지"

Phase 0 승인: 완료. 주제 카드 `ep01_topic_card.md` 기반.

## Story Circle — EP01

### 1. YOU (일상) → HOOK 시작

Vee는 지금 뭘 믿고 있나?

> "AI한테 시키면 뭐든 만들 수 있다." 사흘 만에 에이전트 5개를 만들었다. BUILD SUCCESS. 자축 중.

### 2. NEED (위기) → HOOK 끝

무슨 사건이 터지나? 어떤 질문이 던져지나?

> 모니터 5개가 동시에 빨간 에러. 폭포처럼 쏟아진다. "...뭐?" — Vee에겐 빨간 글자 덩어리일 뿐이다. 읽을 수 없다. 뭐가 터졌는지도 모른다.

### 3. GO (진입) → SITCOM ACT 1 시작

Vee가 처음 시도하는 건? (항상 틀린 접근이어야 함)

> 3일 전으로. Vee의 바이브코딩 몽타주 — "만들어줘" → "됐다!" 반복. 빠르게 불어나는 코드. 뭘 시키든 됐다. "이거면 뭐든 만들겠는데?" — 이게 함정.

### 4. SEARCH (몸부림) → SITCOM ACT 1 끝

어떻게 더 꼬이나? Bee는 어디서 끼어드나?

> Bee가 책상 위에 앉아 있다. 한쪽 눈 뜨며 "...뭐 하는 거야." Vee: "엇, 너 누구야?" Bee: "스펙이 뭔데." Vee: "...스펙?" Bee: "됐다. 알아서 해." 떠남. Bee는 힌트만 던지고 사라진다. 설명은 EP03부터.

### 5. FIND (발견) → EXPLAINER

무슨 개념이 문제를 설명하나? 메타포 ID는?

> **Act1-#1** (설계도) + **Act1-#2** (무작위 쌓기) + **Act1-#9** (스케이트보드→자전거→자동차). 설계도 없이 쌓으면 무너진다. 스펙 = 설계도. 처음부터 완벽할 필요 없다, 스케이트보드면 된다. "이건 스케이트보드다"가 스펙의 시작.

### 6. TAKE (대가) → SITCOM ACT 2 시작

Vee가 뭘 바꾸거나 포기하나?

> Vee가 코드를 멈춘다. 키보드에서 손을 뗀다 — "일단 만들자" 태도를 포기하는 것. 대신 빡침을 종이에 적기 시작한다. "뭐가 빡치냐면." 코딩이 아니라 정리. 이건 Bee가 시킨 게 아니다. 혼자 빡쳐서 하는 거다.

### 7. RETURN (복귀) → SITCOM ACT 2 끝

원래 상황으로 어떻게 돌아오나?

> 짜증을 적다 보니 "뭘 만들 건지"가 나온다. "밖에서도 집 컴퓨터를 쓰고 싶다." 종이를 들고 모니터를 다시 본다. 아까 빨간 글자 덩어리였던 에러 메시지가 — 한 줄이 읽힌다. 소스: act1-1 "나는 대체 뭘 만들고 있는 거지?" 반전.

### 8. CHANGE (변화) → ENDING

Vee가 어떻게 달라졌나? **Step 2의 같은 장면에서 다른 반응을 보여야 한다.**

> **Step 2와 같은 장면.** 모니터 5개. 빨간 에러. Vee가 앉아 있다. 하지만 당황하지 않는다. 종이 한 장을 모니터 옆에 핀으로 꽂는다. "아직 다 터져 있다. 근데 이제 뭘 고쳐야 하는지 안다." Bee가 화면 구석에서 0.5초 고개 끄덕. 바로 무표정.

### Opening Image ↔ Final Image

- **오프닝**: Vee가 모니터 앞에서 두 팔 벌려 "됐다!" — 자축. 초록 불. 세상 다 가진 표정.
- **파이널**: Vee가 **같은 모니터** 앞에 앉아 있다. 빨간 에러. 하지만 당황 대신 **종이 한 장을 들고 있다**. 차분.

## Story Spine — EP01

```
옛날 옛적에, Vee는 AI한테 시키면 뭐든 만들 수 있다고 믿었다.
매일매일, 그녀는 "만들어줘"라고 치고 "됐다!"라고 외쳤다.
그러던 어느 날, 앱을 돌렸는데 전부 터졌다.
그래서, AI한테 "고쳐줘"를 반복했지만 고치면 다른 데서 터졌다.
그래서, 빡쳐서 뭐가 짜증나는지 종이에 적기 시작했다.
마침내, 적어놓은 짜증이 "뭘 만들 건지"가 됐다.
그 후로, 에러는 아직 있지만 뭘 고쳐야 하는지는 안다.
```

| SITCOM1 퇴장 | 혼란 ("스펙이 뭔데?"), 잔뜩 찔림 | 한심 + "됐다. 알아서 해." 퇴장 | 일방적 — Bee가 관심 없음 |

| ENDING | 결연 + 차분, "뭘 고쳐야 하는지 안다" | 고개 끄덕 0.5초 → 무표정 | 첫 접점 |

### 시리즈 바이블 교차 검증

**바이블 EP01 아크**: "자신만만 → 충격", Vee 첫 바이브코딩 성공 → 30초 후 전부 폭발
**대본 아크**: 자신만만(HOOK) → 충격(HOOK) → 혼란(SITCOM1) → 빡침(SITCOM2) → 차분(ENDING)
→ 일치. "자신만만 → 충격"이 HOOK에서 달성되고, ENDING에서 "차분한 결연"으로 닫힘.

**바이블 Bee EP01**: 적대적 ("나한테 왜 물어봐"), Vee 무시, 귀찮음 폭발
**대본 Bee**: "스펙이 뭔데" → "됐다. 알아서 해." → 대사 없이 슬쩍 관찰
→ 일치. 설명은 안 함. "알려줘"는 EP03부터.

**바이블 관계**: EP01 = 남남 (Bee: "누구세요")
**대본 관계**: Vee "엇, 너 누구야?" → ENDING에서 Bee 고개 끄덕 0.5초 (첫 접점)
→ 일치. 남남에서 첫 접점까지만.
