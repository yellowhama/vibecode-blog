# 주제 카드 — EP01

## 주제
> 스펙

## 세 가지

| | 내용 |
|--|------|
| **뭔지** | "뭘 만들 건지" 적어둔 것. 목적/이유/방법/수단. |
| **없으면** | AI한테 하나씩 물어보면 핑퐁 무한루프. 고치면 옆에서 터짐. |
| **있으면** | 뭘 만드는지 알고 시작. 에러가 있어도 뭘 고칠지 앎. |

| 2막 (뭔지) | 스펙은 이런 거다 | 해설 | 설계도 메타포 + 네 칸(목적/이유/방법/수단) |
| 3막 (있으면) | 스펙 있으면 달라진다 | 시트콤 | 058: 짜증→질문→스펙 |
