# AI가 해줄 수 있는 기능(상세페이지 자동화 관점)

이 문서는 “AI로 뭘 할 수 있냐”를 **기능 단위**로 정리한 것입니다.  
핵심은 “사람이 잘 쓰게 설명”이 아니라, **AI가 결과물을 파일로 찍어내게** 만드는 겁니다.

## 1) 기획 자동화(Planner)

- 입력: 제품 정보(SSOT)
- 출력: `03_section_plan.json`
- 해주는 것:
  - 포지셔닝(말의 방향) 3개 만들기
  - 그중 1개 선택(이유 포함)
  - 섹션(Hero/USP/Proof/FAQ/CTA)별 목표/메시지/필요 이미지 정의

## 2) 카피 자동화(Copywriter)

- 입력: `03_section_plan.json` + SSOT
- 출력: `04_copy_deck.md`
- 해주는 것:
  - 섹션별 헤드라인/본문/불릿/CTA를 버전 A/B로 생성
  - Fact 부족한 곳은 “TODO 자리”만 만들고 과장하지 않게 제어

## 3) 디자인 자동화(Designer)

- 입력: `03_section_plan.json`
- 출력: `05_wireframe.md`
- 해주는 것:
  - “예쁜 디자인”이 아니라 **블록 배치**를 결정
  - 각 섹션에 이미지 슬롯/텍스트 블록/표/아이콘을 어디에 놓을지 고정
  - 모바일 기준으로 길이 제한(넘치면 망가짐)

## 4) 이미지 자동화(Image)

사진이 없거나 별로일 때, AI는 아래를 도와줄 수 있습니다.

- (안전) 보조 이미지 만들기:
  - 배경 패턴, 아이콘, 상황 이미지(라이프스타일) 프롬프트 생성
- (가능) 핸드폰 제품 사진 “보정”:
  - 조명/배경 정리, 색감 통일, 그림자 정돈 같은 편집 프롬프트 생성
- 출력: `07_image_prompts.md`
- (같이 생성): `08_shot_list.md`(다음 루프용 촬영 리스트)

## 5) 컬러 자동화(Palette)

- 입력: 브랜드 컬러(있으면) 또는 “톤” 요구사항
- 출력: `06_colors.json`
- 해주는 것:
  - 기본 UI 팔레트 1세트(안전)
  - 트렌드 느낌 팔레트 1세트(영감)
  - hex 코드로 납품(디자인/코드 둘 다 사용 가능)

## 6) QA 자동화(QA)

- 입력: `04_copy_deck.md` + SSOT 규칙
- 출력: `09_qa_report.md`
- 해주는 것:
  - 근거 없는 주장/수치 탐지
  - 금칙어 탐지
  - 필수 고지 누락 탐지
  - 문장 길이/중복/애매함 지적 + 교체 문장 제안

## 7) 조합(자동화)

위 기능은 따로 쓰면 “좋은 답변”에서 끝납니다.  
자동화는 “파일로 저장”하고 “다음 단계가 그 파일을 읽는 것”까지 묶어야 됩니다.

- 한 번 실행하면 `runs/.../`에 아래가 생기게 만들기:
  - `03_section_plan.json` -> `04_copy_deck.md` -> `05_wireframe.md` -> `06_colors.json` -> `07_image_prompts.md` -> `09_qa_report.md`

실전에서는 `prompts/00_orchestrator.md` 같은 “마스터 프롬프트” 하나로 묶는 게 가장 단순합니다.
