# 최종까지: AI가 할 수 있는 기능 “전체 리스트”

전제: “AI가 한다”는 건 보통 2가지 중 하나입니다.
- AI가 **결정/생성**한다(텍스트/구조/디자인/프롬프트)
- AI가 **실행**한다(API/MCP로 파일 생성, 업로드, 변환, 검사)

아래는 상세페이지를 끝까지 만든다고 했을 때, 기능을 빠짐없이 나눈 목록입니다.

## A. 입력 수집/정리(맨땅 탈출)

- 제품 현물/라벨/패키지에서 Fact 추출(OCR/요약)
- Fact/Guess/Question 분리해서 SSOT 자동 생성
- 부족한 정보만 “질문 10개”로 뽑기

## B. 리서치/기획(마케터/기획자 핵심)

- 경쟁사/레퍼런스 상세페이지 수집(스와이프 파일)
- 타겟 페르소나 가정/선택(3개 -> 1개)
- 포지셔닝(말의 방향) 3개 생성 -> 1개 선택
- 메시지 맵(USP 3개, Proof 3개, FAQ 5개)

## C. 카피/콘텐츠

- 섹션별 헤드라인/본문/불릿/CTA 생성(A/B)
- 카테고리별 FAQ 생성(배송/교환/주의/AS)
- “근거 없는 주장” 자동 탐지/삭제
- SEO 메타(타이틀/디스크립션/OG 문구) 초안 생성

## D. 디자인(초안 -> 시안)

- 와이어프레임(블록 배치) 생성
- 섹션 템플릿 선택(5섹션 고정)
- 컬러 팔레트(hex) 생성(안전 1 + 트렌드 1)
- 타이포 규칙(제목/본문/버튼/표) 생성
- 아이콘/배지/콜아웃 문구 규칙 생성

## E. 이미지/비주얼

- 제품 사진 보정 프롬프트 생성(핸드폰 사진 기반)
- 배경/패턴/아이콘/인포그래픽 생성 프롬프트 생성
- 이미지 리사이즈/압축/파일명 규칙 자동화
- alt 텍스트 자동 생성

## F. 구현/패키징(플랫폼은 나중에)

- HTML/CSS 초안 렌더링(플랫폼 중립)
- 플랫폼별 변환(마켓 에디터 블록/자사몰 템플릿)
- 구성 요소(텍스트/이미지/표) JSON으로 패키징

## G. QA/컴플라이언스(사고 방지)

- 금칙어/과장표현 자동 탐지
- 필수 고지 누락 탐지(배송/교환/주의/AS)
- 문장 길이/중복/모호함 탐지
- “Fact 기반” 여부 검사(근거 없는 문장 표시)

## H. 퍼블리시/운영

- 에셋 업로드(스토리지/CMS) 자동화
- 퍼블리시 체크리스트 자동 생성
- A/B 테스트 변형안(헤드라인/CTA) 생성

## I. 런칭 이후 개선

- 성과 지표(체류/전환/이탈) 요약 리포트 생성
- 문제 섹션 진단(어디서 이탈하는지 가정)
- 개선안 3개 생성 -> 우선순위 정렬

## 현실 체크(중요)

AI가 최종까지 “전부” 할 수 있어도,
Fact/가격/정책/인증 같은 핵심은 사람이 확인해야 안전합니다.
