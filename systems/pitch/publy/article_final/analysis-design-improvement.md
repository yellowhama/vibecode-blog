# 상세페이지 디자인 개선 분석

> 날짜: 2026-03-22
> 대상: publy.pen 15개 프레임 vs deep-research 리서치 결과

---

## 1. 적용 안 된 디자인 기법

### 1.1 타이포그래피 위계 부족

- **리서치 기준**: 헤드라인 대 본문 비율 최소 3:1, 프리미엄은 5:1+
- **Apple 스케일**: H1(80-120px/900w) → H2(48-64px/700w) → H3(28-36px/600w) → Body(19-21px/400w)
- **현재 문제**: 원본(bi8Au)의 헤드라인과 본문 크기 차이가 작다. 헤드라인이 눈에 안 꽂힌다
- **잘 된 예**: E2(에디토리얼 리서치) — "경북 부사 사과, 한 박스로 준비"가 크게 들어감

### 1.2 풀블리드 히어로 미적용

- **리서치 기준**: 첫 화면 = 풀블리드 제품 이미지 + 1줄 킬러카피 (한국 시장 기본)
- **현재 문제**: E2/F2/G2(리서치 버전)에만 풀블리드. 원본/E/F/G는 패딩 안에 갇혀있음
- **권장**: 모든 버전에 풀블리드 히어로 적용

### 1.3 스펙 바 / 숫자 증거 섹션 부분 적용

- **리서치 기준**: Social Proof — 대형 숫자로 누적 판매량/리뷰 강조 (와디즈 고전환 패턴)
- **현재 문제**: E2, G2에만 스펙 바 있음 (2kg, 10과, 경북, 2~3일). 원본/F에는 없음
- **권장**: 모든 버전에 스펙 바 또는 숫자 증거 섹션 추가

### 1.4 배경색 교차 리듬 약함

- **리서치 기준**: White → Light Gray → White → Dark 교차 (밀도 변화로 시선 유도)
- **현재 문제**: 원본은 올리브 단색 톤. F(스칸디)는 크림 단색. 섹션 간 리듬감 부족
- **잘 된 예**: E2 — 흰 배경 → 다크 반전 Proof → 다시 밝은 배경

### 1.5 지그재그 레이아웃 미적용

- **리서치 기준**: [이미지|텍스트] ↔ [텍스트|이미지] 교차 (와디즈 고전환 패턴)
- **현재 문제**: 전부 세로 스택. 좌우 교차 레이아웃 없음

### 1.6 소프트 섀도 / 글래스모피즘 미적용

- **리서치 기준**: `box-shadow: 0 20px 60px rgba(0,0,0,0.08)` + glassmorphism (2026 트렌드)
- **현재 문제**: F(스칸디)에 약한 섀도 1개만. 나머지 전부 플랫

## 2. 적용 잘 된 것

- 스타일 태그 분기 (E/F/G) — 같은 카피로 다른 느낌
- 리서치 패턴 적용 버전 (E2/F2/G2) — 풀블리드, 스펙바, 오버레이
- 780px 모바일 최적화 폭
- 섹션 구조 (Hero → USP → Proof → FAQ → CTA)
- Unsplash 이미지 연동

## 4. 한국 시장 고려사항

### Pencil 출력 = 코드 (React/HTML), 마켓플레이스 = 이미지 (JPEG)

- 쿠팡(780px), 네이버(860px) — 이미지 기반 상세페이지
- Pencil로 만들면 export → 스크린샷 변환 필요
- 자사몰이면 코드를 바로 쓸 수 있음

### 한국 상세페이지 전환 구조 (와디즈 검증)

| 순서 | 섹션 | 시각 기법 |
|------|------|----------|
| 1 | 후킹 히어로 | 풀블리드 제품 이미지 + 1줄 킬러카피 |
| 2 | 핵심 차별점 3~4개 | 아이콘 + 짧은 텍스트 그리드 |
| 3 | 사회적 증거 | 대형 숫자 (누적 판매/리뷰) |
| 4 | 상세 설명 | 좌우 지그재그 레이아웃 |
| 5 | 사용 시나리오 | 라이프스타일 사진 |
| 6 | 스펙/구성 | 표/그리드 + 구성품 이미지 |
| 7 | 만든 사람 | 인물 사진 + 스토리텔링 |
| 8 | 가격/혜택 | 비교표, 얼리버드 뱃지 |
| 9 | FAQ/배송 | 아코디언 또는 Q&A 블록 |

## 5. 새 디자인 적용 체크리스트

새 프레임을 만들 때 아래를 전부 적용:

- [ ] 풀블리드 히어로 (패딩 0, 제품 이미지 + 그라디언트 오버레이 + 킬러카피)
- [ ] 타이포 위계 5:1+ (H1 48px+ / Body 16px)
- [ ] 배경색 교차 리듬 (밝음 → 어두움 → 밝음)
- [ ] 스펙 바 / 숫자 증거 섹션
- [ ] 지그재그 레이아웃 (좌우 교차) 최소 1개 섹션
- [ ] 소프트 섀도 카드 (`0 20px 60px rgba(0,0,0,0.08)`)
- [ ] CTA 색상 대비 강화
- [ ] 780px 폭 유지
