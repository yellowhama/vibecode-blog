# 스타일 분기 (v2 추가)
ssot.yaml에 `style_preset` 또는 `style_tags` 필드가 있으면:
1. style_preset이 있으면 → 아래 프리셋 매핑에서 태그를 가져온다
2. style_tags가 있으면 → 태그를 그대로 사용한다
3. 둘 다 없으면 → 기본값 fresh-organic 사용

## 프리셋 → 태그 매핑
- fresh-organic: japanese, minimal, cream, organic, warm, soft-corners
- tech-clean: modern, clean, blue-accent, whitespace, webapp, sharp-corners
- luxury-dark: luxury, dark-mode, gold-accent, serif, elegant, premium
- bold-energy: bold, neon, dark-mode, electric, vibrant, rounded
- scandi-calm: scandinavian, pastel, calm, soft-corners, friendly, organic

## 스타일 적용 순서
1. Pencil `get_style_guide(tags)` 호출 → 사양서 수신
2. 사양서에서 Color System → 06_colors.json에 반영
3. 사양서에서 Typography → 폰트/사이즈 결정
4. 사양서에서 Corner Radius → 조립 시 적용
5. `get_guidelines(page_type)` 호출 → 섹션 구조 규칙 적용
   - page_type은 ssot.yaml의 `page_type` 필드 (기본값: landing-page)

# 페이지 타입 분기 (v2 추가)
ssot.yaml에 `page_type` 필드가 있으면:
- landing-page → Hero/Benefits/How It Works/Social Proof/Pricing/FAQ/CTA
- web-app → 기능 중심 구조
- mobile-app → 모바일 최적화 구조
없으면 기본값: 상세페이지 구조 (Hero/USP/Proof/FAQ/CTA)

# 출력
현재 폴더에 `runs/` 폴더를 만들고, 그 안에 새 폴더를 만드세요.
폴더 이름: 오늘 날짜_시간_상품이름 (예: 20260301_160000_apple)

그 안에 아래 파일 10개를 반드시 만드세요.

# 절대 규칙
- 사실만 "사실"이라고 쓰세요.
- 모르는 건 "TODO"로 남기세요. 절대 만들어내지 마세요.
- 추정은 [추정]이라고 표시하세요.
- 수치/효과/인증은 근거가 없으면 쓰지 마세요.
- 짧고 쉬운 한국어로 쓰세요.

# 10개 파일 (이 순서대로)

## 1. 01_intake_report.md — 입력 점검
- 지금 있는 사실 목록
- 빠진 핵심 사실 목록
- 위험 표현이 들어갈 수 있는 지점
- 이번 초안에서 "사실만으로 말할 수 있는 것"과 "말하면 안 되는 것"

## 2. 02_questions_to_answer.md — 품질 올리는 질문
- 최대 10개
- "답하면 품질이 가장 크게 올라가는 질문"만

## 3. 03_section_plan.json — 섹션 기획
- 포지셔닝(말의 방향) 3개 만들고, 1개 선택 (이유 포함)
- 섹션 5개 고정: Hero / USP / Proof / FAQ / CTA
  - page_type이 landing-page면 가이드라인 섹션 흐름 따르기
- 각 섹션: 목적(한 줄), 핵심 메시지 3개, 필요한 사진/표, 필요한 카피

## 4. 04_copy_deck.md — 카피 초안
- 섹션별로: 헤드라인 2개(A/B), 본문(A/B), 불릿 3개(A/B), CTA 버튼(A/B)
- 사실 부족한 부분은 TODO로 남기고 문장 패턴만 제시

## 5. 05_wireframe.md — 블록 배치
- 예쁜 그림이 아니라 "어디에 뭘 놓을지"
- 이미지 자리마다 ID를 붙이세요 (예: IMG-HERO-01)
- 각 이미지 자리: 뒷받침하는 메시지 / 어떤 사진이 좋은지 / 캡션 / alt 텍스트

## 6. 06_colors.json — 색상
- 스타일 가이드가 있으면 → 사양서의 Color System을 그대로 사용
- 없으면 → 기본 팔레트 1개 + 트렌드 팔레트 1개
- 키: bg, surface, text, muted_text, border, accent, accent2, success, warning (전부 hex)
- 추가 키 (v2): font_primary, font_secondary, corner_radius, spacing_base

## 7. 07_image_prompts.md — 이미지 지시
- 이미지 ID별로 프롬프트 작성 (한국어 + 영어)
- 제품 사진 없으면 만들어내지 말고, 보조 이미지(배경/아이콘)만 제안
- **AI 생성 이미지에는 반드시 'AI 생성' 표시 필요 플래그 추가** (v2 추가)

## 8. 08_shot_list.md — 촬영 목록
- 필수 3장: 정면 / 디테일 / 사용 상황
- 추천 6장까지 확장
- 각 항목: 뭘 찍나 / 왜 필요한가 / 주의사항(빛, 각도) / 연결 이미지 ID

## 9. 09_qa_report.md — 검수 리포트
- 체크: 근거 없는 주장, 금지 표현, 필수 고지 누락, 긴 문장, 중복
- 문제마다: 왜 문제인지 + 수정 제안
- **컴플라이언스 통합 검수 (v2 추가):**
  - AI 기본법: 'AI 생성' 표시 누락 체크
  - 표시광고법: 최상급 표현, 근거 없는 수치, 허위·과장 체크
  - 필수 고지: 원산지, 가격, 배송, 교환/환불 누락 체크

## 10. run_summary.md — 실행 요약
- 15줄 이내
- 선택한 포지셔닝 / 적용된 스타일 프리셋 / 중요한 TODO 5개 / 다음에 바꿀 것 3개
