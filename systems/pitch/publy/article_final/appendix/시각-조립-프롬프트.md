# 부록 D: 시각 조립 프롬프트

이 프롬프트를 Claude Code에 붙여넣으면, 전반부 텍스트 파일을 읽어서 상세페이지 레이아웃을 자동으로 만듭니다.

---

## 사용법

1. 전반부 공장을 돌려서 `runs/` 폴더에 텍스트 파일 10개가 있어야 합니다.
2. 아래 프롬프트를 Claude Code에 붙여넣습니다.
3. `[RUN_PATH]`를 실제 경로로 바꿉니다.

---

## 프롬프트

```
다음 파일을 읽고 상세페이지 레이아웃을 Pencil로 만들어줘.

입력 파일:
- [RUN_PATH]/03_section_plan.json — 섹션 구조
- [RUN_PATH]/04_copy_deck.md — 카피 (Version A 사용)
- [RUN_PATH]/05_wireframe.md — 블록 배치
- [RUN_PATH]/06_colors.json — 컬러 팔레트

요구사항:
1. Pencil 문서를 새로 열어.
2. 세로 레이아웃, 가로 780px로 메인 프레임을 만들어.
3. section_plan의 섹션별로 프레임을 만들어.
4. 각 프레임에 copy_deck Version A의 텍스트를 배치해.
   - 헤드라인: 24~32px, 볼드
   - 본문: 14~16px
   - 불릿: 14px
   - CTA 버튼: 배경 accent 색, 흰색 글자
5. colors.json의 색상을 적용해.
   - bg → 메인 배경
   - surface → 카드/표 배경
   - accent → CTA 버튼, 강조
6. wireframe의 IMG-* 위치에 이미지 플레이스홀더(회색 사각형)를 만들어.
   - 각 플레이스홀더에 IMG-* ID를 라벨로 표시해.
7. 완성되면 스크린샷을 찍어서 보여줘.

주의:
- 완성 디자인이 아니라, "수정하기 쉬운 뼈대"가 목적이야.
- 이미지 슬롯은 비워둬. 나중에 사진 기계로 채울 거야.
- TODO인 항목은 그대로 TODO로 남겨.
```
