# 클로드 코드로 상세페이지 초안 공장 만들기

---

## 먼저 한 줄

"상세페이지를 잘 쓰는 법"이 아닙니다.
**상세페이지 초안을 반복 생산하는 공장**을 만듭니다.

재료 한 장 넣으면, 텍스트도 나오고 **페이지도** 나옵니다.

여기서 "자동화"란,
초안은 AI가 뽑고, 최종 승인은 사람이 하는 상태입니다.

---

## 1. 상세페이지 하나에 반나절

월요일 아침.
새 상품이 왔다.
사과. 2킬로 한 박스.
상세페이지를 만들어야 한다.

정보를 모은다.
슬랙에서 찾는다. 없다.
노션에서 찾는다. 반만 있다.
엑셀에서 찾는다. 버전이 3개다.

사진.
정면샷 하나. 형광등 아래에서 찍은 것.
"이거 하나로 뭘 어쩌라고."

정책.
배송비? 모른다. 교환/환불? 아직 안 정해졌다.

그래도 만든다.
상사가 "오늘 중으로"라고 했으니까.

3시간 걸렸다.

근데 진짜 시간을 잡아먹은 건 만드는 게 아니었다.
정보 찾는 데 1시간. 슬랙에 물어보고, 답 기다리고, 다시 물어보고.
만드는 시간보다 찾는 시간이 더 길었다.

다음 주 헤드폰, 그 다음 주 폼보드. 매번 처음부터. 매번 3시간.

한 달이면 상품이 4~5개 온다.
4개 × 3시간 = 12시간.
한 달에 이틀 반을 상세페이지에 쓰고 있었다.

근데 진짜 문제는 시간이 아니었다.

매번 처음부터라는 거다.
저번에 사과 만들면서 겪은 시행착오가, 이번 헤드폰에 하나도 안 남는다.
사람이 바뀌면 더하다. 인수인계? 그런 거 없다.

매번 처음부터. 매번 반나절. 매번 같은 실수.

## 2. 공장이 필요하다

문제를 다시 봤다.

매번 3시간 걸리는 이유.
실력이 아니었다.
매번 처음부터 시작하기 때문이었다.

에디봇은 사진 넣으면 페이지가 나온다. 한 번이면 끝이다.
망고보드도 비슷하다.
도구는 좋다. 하지만 1회성이다.
같은 재료로 다시 돌리면 같은 결과가 나올까? 담당자가 바뀌면?
여기서 공장이 달라진다.

공장은 다르다.
같은 재료 넣으면, 같은 결과가 나온다.
재료만 바꾸면, 다른 제품이 나온다.
매번 처음부터가 아니라, 매번 같은 라인이 돌아간다.

여기서 중요한 거.

AI가 상세페이지를 "만들어주는" 게 아니다.
AI가 **공장을 만들어주는** 거다.

"사과 상세페이지 만들어줘."
이건 장인한테 부탁하는 거다. 한 번이면 끝이다.

"상세페이지 초안을 찍어내는 시스템을 만들자."
이건 공장을 세우는 거다.
사과도 되고, 헤드폰도 되고, 폼보드도 된다.
재료만 바꾸면 된다.

그리고 상세페이지에 얽매일 필요도 없다.

Apple.com의 제품 페이지를 봐라. Hero, 핵심 기능, 스펙 비교, CTA.
SaaS 랜딩 페이지도 똑같다. Hero, 가치 제안, 작동 방식, 가격, FAQ, CTA.
구조가 같다. **재료(카피)는 같고, 뼈대(템플릿)만 다르다.**

실제로 같은 사과 카피를 Apple 제품 페이지 스타일과 SaaS 랜딩 페이지 스타일로 찍어봤다.
카피 한 줄 안 고쳤다. 뼈대만 바꿨다. 둘 다 된다.

[캡처: Apple 랜딩 스타일 — `PENCIL-TEMPLATE-C.png`]
[캡처: SaaS 랜딩 스타일 — `PENCIL-TEMPLATE-D.png`]

이게 공장이다.

공장에는 방이 두 개다.

**기획실.**
재료를 넣으면 기획 서류 11장이 나온다.
카피, 배치도, 색상, 촬영 목록, 검수 리포트.

**조립라인.**
서류를 넣으면 눈에 보이는 페이지가 나온다.
글은 레이아웃 기계가 찍고, 사진은 사진 기계가 찍는다.

## 3. 재료 한 장

공장을 세우려면 설계도가 필요하다.
상세페이지 공장의 설계도는 간단하다.

**"제품 정보 한 장."**

제품에 대해 아는 걸 한 장에 모은다.
상품명. 카테고리. 가격. 구성. 크기. 무게.
사용법. 타겟. 배송. 교환/환불.

규칙은 하나다.

**아는 건 적는다. 모르는 건 비워둔다.**

사과로 해봤다.
책상 위에 사과 박스 놓고, 아는 것만 적었다.

| 항목 | 내용 |
|------|------|
| 상품명 | 부사 사과 |
| 카테고리 | 과일 |
| 한 줄 설명 | 먹는 생과일 |
| 구성 | 2kg (10과) 1박스 |
| 크기 | 손바닥 크기 (대략) |
| 사용법 | 세척 후 섭취 |
| 가격 | (비워둠) |
| 원산지 | (비워둠) |
| 배송 | (비워둠) |
| 교환/환불 | (비워둠) |
| 참고 페이지 | (비워둠) |
| **스타일** | **(비워둠 — 나중에 추가)** |

반이 비었다.

처음엔 불안했다. "이렇게 빈칸이 많은데 괜찮나?"
괜찮다.
비어있는 건 "아직 모른다"는 뜻이다.
채워 넣으면 다음에 더 좋아진다.

빈칸이 있으면 AI가 어떻게 하냐고?
빈칸은 빈칸으로 남긴다. 지어내지 않는다.
"가격: TODO (확인 필요)"라고 쓴다.
이건 나중에 사람이 채우면 된다.

여기서 절대로 하면 안 되는 게 있다.

**모르는 걸 적지 마라.**

"아마 경북일 거야" — 이건 추정이다.
사실 칸에 쓰면 AI가 사실로 받아들인다.
그러면 카피에 "경북산 사과"가 버젓이 나온다.
아닐 수도 있는데.
고객이 보고 산다. 경북이 아니면? 클레임이다.

사실, 추정, 질문.
이 셋을 섞으면, AI도 헷갈린다. 사람도 헷갈린다.

그래서 칸을 나눴다.

- **사실**: 라벨, 스펙표, 확인된 정보만
- **추정**: "아마 ~일 것 같다"는 따로 모음
- **질문**: 반드시 확인해야 할 것

이렇게 나누면 AI가 사실만 카피에 쓴다.
추정은 "확인 필요"로 남긴다.
질문은 "다음 루프에서 해결할 것"으로 정리한다.

적는 데 10분이면 된다.
이 한 장이 공장의 설계도다.

한 가지 더.
**참고 페이지** 칸이 있다.
같은 카테고리에서 잘 만든 상세페이지 URL을 2~3개 넣는다.
있으면 넣고, 없으면 비워둔다.
비워두면 공장이 알아서 조사한다. 넣어두면 더 정확하게 조사한다.
이건 다음 섹션에서 설명한다.

## 4. 지시서를 붙여넣고 돌린다

설계도를 만들었다.
이제 공장을 돌린다.

도구는 Claude Code다.
터미널에서 돌아가는 AI 도구다.
채팅창이 아니라, 파일을 직접 만들어준다.

공장이 카피를 쓰기 전에 먼저 하는 일이 있다.
**숙제를 한다.**
기준 없이 만들면 감으로 만든다.
그래서 공장이 먼저 시장 조사를 한다.

**"이 카테고리에서 잘 팔리는 상세페이지는 어떻게 생겼나?"**

상세페이지란 뭔지.
왜 필요한지.
구매자가 뭘 확인하는지.
누가 잘 만들었는지.

이걸 조사해서 설계 기준 3개를 뽑는다.

사과 카테고리에서 나온 기준:
1. 모바일 첫 화면에 산지 + 구성이 보여야 한다.
2. 사진이 부족하니 스펙 카드로 신뢰를 보강한다.
3. FAQ를 두텁게 해서 CS 문의를 줄인다.

이 기준이 있으니까, 섹션 기획이 감이 아니라 근거가 된다.

설계도(제품 정보 한 장)를 폴더에 넣고,
지시서(마스터 프롬프트)를 붙여넣고,
실행한다.

10분 뒤.
파일 11개가 생긴다.

| # | 파일 | 하는 일 |
|---|------|--------|
| 1 | 입력 점검 | 지금 뭐가 있고, 뭐가 없는지 |
| 2 | 품질 올리는 질문 | 이것만 답하면 다음에 확 좋아지는 질문 10개 |
| 2b | 디자인 리서치 | 이 카테고리에서 잘 팔리는 페이지는 어떻게 생겼나 |
| 3 | 섹션 기획 | 어디서 무슨 말을 할지 (리서치 기반) |
| 4 | 카피 초안 | 헤드라인, 본문, 버튼 문구 (2개씩) |
| 5 | 블록 배치 | 글과 사진이 어디에 들어가는지 |
| 6 | 색상 | 페이지 색깔 |
| 7 | 이미지 지시 | 사진 보정/보조 이미지 가이드 |
| 8 | 촬영 목록 | 다음에 찍어야 할 사진 |
| 9 | 검수 리포트 | 과장/금지 표현/빠진 고지 자동 체크 |
| 10 | 실행 요약 | 이번 결과 + 다음에 할 일 |

아까 재료 한 장에 "참고 페이지"를 넣어뒀으면?
추정 대신 실제 레퍼런스를 기반으로 분석한다.

근데 첫 가동은 완벽하지 않다.
당연하다.
설계도에 빈칸이 많았으니까.

카피를 보면 TODO 투성이다.
"가격: TODO (확인 필요)."
"배송: TODO (정책 확인 후 입력)."

그런데.

**AI가 질문을 한다.**

[캡처: 품질 올리는 질문 목록 — `CAP-01_questions_trackA1.png`]

"이것만 답해주시면 다음 초안이 확 좋아집니다."

질문 10개.
"가격이 얼마인가요?"
"원산지가 어디인가요?"
"배송은 어떻게 되나요?"
"타겟이 누구인가요?"

이게 핵심이다.
AI가 만들어주는 게 아니라,
**AI가 뭘 채워야 하는지 알려주는 거다.**

블록 배치에는 이미지 이름표가 붙어있다.
`IMG-HERO-01`. `IMG-PROOF-01`.
이 이름표가 나중에 조립라인에서 사진과 연결된다.

## 5. 5개만 답한다. 다시 돌린다. 다르다.

첫 가동에서 AI가 던진 질문 10개.
그중 5개만 답했다.

| 질문 | 답 |
|------|---|
| 가격 | 12,900원 |
| 구성 | 2kg, 10과 |
| 원산지 | 경북 부사 |
| 배송 | 산지 직송, 상온택배 2~3일 |
| 타겟 | 가정용 간식, 명절 선물 |

설계도에 5줄 추가했다.
같은 공장을 다시 돌렸다.

결과가 다르다.

첫 번째 카피:
> "사과입니다. 세척 후 바로 드세요."

두 번째 카피:
> "경북 부사 사과, 2kg(10과) 한 박스. 산지에서 바로 보냅니다."

첫 번째 검수 결과: **불합격** — 핵심 정보 부족.
두 번째 검수 결과: **합격** — 사실 기반 카피, 보강 필요 항목 2개.

[캡처: 첫 번째 vs 두 번째 카피 비교]

같은 공장. 재료만 보강했다.
결과가 이렇게 다르다.

이게 공장이다.
같은 설계도, 더 좋은 재료, 더 좋은 결과.
매번 처음부터가 아니라, 매번 이전보다 나아진다.

아래 Pencil 스크린샷이 2차 실행 결과로 조립한 Hero 섹션이다.
재료를 보강하니, 헤드라인에 구성·원산지·배송이 모두 들어간다.

## 6. 법이 바뀌었다

2026년 1월 22일.
AI 기본법이 시행됐다.

상세페이지에 직접 적용되는 규정이 생겼다.

### AI 생성물 표시 의무

생성형 AI로 만든 결과물에 **'AI 생성' 표시가 필수**다.
법인, 단체, 개인 모두 포함.
1인 셀러도 해당된다.

커머스 상세페이지, 인플루언서 협찬 광고 등 상업적 생성물 모두 대상이다.
위반 시 시정명령 → 불이행 시 **최대 3,000만 원 과태료.**
계도기간(2026.07.21까지)이 있지만, 시스템은 미리 만들어두는 게 맞다.

### 표시광고법 — 금지 표현

AI가 만들어도 표시광고법은 동일하게 적용된다.

- **최상급 표현**: "최고", "100%", "독보적" — 입증 못 하면 위반
- **허위/과장**: 근거 없는 수치, 효과, 비교
- 악의적 허위·조작 시 **손해액의 최대 5배** 징벌적 손해배상

"최고의 사과"를 AI가 썼든 사람이 썼든, 근거 없으면 같은 위반이다.

### 이걸 사람이 매번 하면 놓친다

10페이지짜리 상세페이지에서 "최고" 한 단어. 근거 없는 당도 수치. 빠진 AI 생성 표시.
사람 눈으로 매번 잡기 어렵다. 자동으로 잡으면 시스템이다.

이 글에서 만드는 공장의 검수 리포트(9번 파일)가 정확히 이걸 한다.
한국에 상세페이지 전용 표시광고법 자동 검수 도구는 아직 없다. 그래서 직접 만든다.

## 7. 빈칸이 거짓보다 낫다

여기서 가장 많이 받는 질문.

"AI가 '최고의 사과'라고 쓰면 어쩌나요?"
"없는 인증을 만들어내면요?"
"가격을 지어내면요?"

이제 이건 단순한 품질 문제가 아니다.
6절에서 봤듯이, **법적 리스크**다.
과태료도 낼 수 있다.

### 텍스트 안전장치

세 가지가 있다.

**첫째, 모르면 모른다고 한다.**

가격을 안 넣었으면, AI가 가격을 지어내지 않는다.
대신 이렇게 쓴다:

> 가격: TODO (판매처 확인 필요)

빈칸은 "다음에 채우면 된다."
거짓은 "나중에 전부 다시 해야 한다."

**둘째, 금지 표현을 자동으로 잡는다.**

일부러 넣어봤다.
카피에 "최고의 사과"를 적었다.

검수 리포트가 바로 잡았다:
> "최고" — 비교 근거 없음. 삭제 권장. (표시광고법 대응)
> 수정 제안: "경북 부사 사과입니다."

[캡처: TODO 안전 장치 — `CAP-04_qa_trackB1_safe_fail.png`]

[캡처: 금지 표현 자동 검수 — `CAP-05_qa_failure_demo_forbidden.png`]

**셋째, 근거 없는 수치를 차단한다.**

"당도 13 brix" — 이건 어디서 나온 숫자인가?
근거가 없으면 AI가 "(근거 필요)"를 붙인다.
스펙표나 검사 결과가 있을 때만 숫자를 쓴다.

### 이미지에서도 같다

텍스트에서 "모르는 걸 적지 마라."
이미지에서도 같은 원칙이 있다.

**"없는 제품을 만들지 마라."**

만드는 것: 배경, 분위기. 만들지 않는 것: 실제 제품, 라벨, 측정.
AI 이미지에도 **'AI 생성' 표시가 필요하다** (→ 6절).

**빈칸이 거짓보다 낫다. 텍스트에서도, 이미지에서도, 법적으로도.**

> 부록에 검수 체크리스트를 넣어뒀습니다.
> → **부록 C: 검수 체크리스트**
> → **부록 E: 시각 검수 체크리스트**

## 8. 매뉴얼을 건다

사과를 2~3번 돌렸다.
그 다음 헤드폰을 돌렸다.

느꼈다.
톤이 다르다.
사과에서는 "친절한 말투"였는데, 헤드폰에서는 "딱딱한 설명체"가 나왔다.
배송 안내도 매번 다른 형식으로 나온다.

이유는 간단했다.

규칙이 내 머릿속에만 있었다.

"우리 브랜드는 이런 톤이야."
"배송 안내는 이 형식으로 써야 해."
"이 카테고리에서는 이런 표현 쓰면 안 돼."

이걸 내가 기억하고 있으면, 매번 다르게 나온다.
파일에 적어두면, 매번 같게 나온다.

그래서 매뉴얼을 만들었다.

| 매뉴얼 | 하는 일 |
|--------|--------|
| 톤앤매너 | "이 문체로 써. 이건 쓰지 마." |
| 섹션 규칙 | 각 블록에서 할 말, 하지 말 말 |
| 가격/정책 | 가격 표기법, 배송/교환/환불 템플릿 |
| 검수 기준 | 과장/금지 표현/필수 고지 체크리스트 |
| 시각 기준 | 폰트 크기, 컬러 팔레트, 모바일 레이아웃 |

실제 톤 가이드 예시:

| 쓰는 표현 | 쓰지 않는 표현 |
|-----------|--------------|
| "경북 부사 사과입니다." | (X) "최고급 프리미엄 사과" |
| "세척 후 바로 드세요." | (X) "놀라운 신선함을 경험하세요!" |
| "2kg(10과) 박스 구성입니다." | (X) "푸짐한 양으로 온 가족이 즐기세요" |

이 파일들을 공장에 거는 거다.
AI가 초안을 만들기 전에 매뉴얼을 먼저 읽는다.
그러면 톤도, 형식도, 검수 기준도, 디자인도 매번 같다.

머릿속에 있으면 기준이다.
파일에 있으면 시스템이다.

담당자가 바뀌어도 같은 결과.
AI 모델이 바뀌어도 같은 결과.
매뉴얼이 있으니까.

사과 공장에 헤드폰 재료를 넣으면?
헤드폰 초안이 나온다.
카테고리가 달라지면 매뉴얼을 하나 추가하면 된다.
전자제품이면 "KC 인증 필수 고지" 매뉴얼을 건다.
식품이면 "원산지/유통기한 필수 고지" 매뉴얼을 건다.

공장은 그대로. 매뉴얼만 바꾼다.

## 9. 조립라인을 돌린다

여기까지가 기획실이다.
카피도 나오고, 배치도 나오고, 검수도 된다.

이제 조립라인이다.
기획실에서 나온 서류를, 눈에 보이는 페이지로 만든다.

도구는 2개다.

**레이아웃 기계 = Pencil.**
Claude Code가 MCP(Model Context Protocol)로 Pencil을 **직접 조작**한다.
사람이 마우스로 배치하는 게 아니라, AI가 프레임을 만들고 텍스트를 넣고 색을 입힌다.
한글이 깨지지 않는다.

**사진 기계 = Gemini.**
이미지 프롬프트를 읽고, 배경·분위기·라이프스타일 사진을 만든다.

왜 나누는가.
전체를 이미지 한 장으로 만들면 글자가 뭉개진다. 한글이 깨진다.
나누면 텍스트는 정확하고, 사진은 예쁘고, 수정은 따로따로.

### Pencil을 쓰는 3가지 이유

**첫째, AI 네이티브.**
AI가 직접 조작하기 좋게 만들어진 도구다.
MCP로 프레임, 텍스트, 색을 바로 만든다.
GUI 디자인 도구인데, API로 조작할 수 있다.

**둘째, 스타일 가이드 내장.**
200가지 넘는 디자인 방향이 태그로 내장돼 있다.
태그 5개면 컬러, 폰트, 간격, 코너 반경까지 전부 나온다.
디자이너가 없어도 일관된 디자인 시스템이 적용된다.

**셋째, GUI + AI 양쪽.**
사람이 눈으로 보고 마우스로 고칠 수 있고,
AI가 코드로 만들 수도 있다.
사람과 AI의 협업 지점이 명확하다.

### 조립 과정

실제로 사과 상세페이지를 Pencil로 조립한 과정이다.

**1단계: 섹션 프레임 5개.**
Hero, USP, Proof, FAQ, CTA.
빈 프레임 5개를 세로로 쌓는다.

[캡처: 섹션 프레임 구조 — `PENCIL-02_section-frames.png`]

**2단계: 카피 배치.**
카피 초안에서 Version A를 골랐다.
헤드라인, 불릿, CTA 버튼 텍스트가 각 섹션에 들어간다.

**3단계: 컬러 적용.**
색상 파일에서 trend_neutral 팔레트를 가져왔다.
배경: 따뜻한 크림색 `#FAF7F2`.
강조: 올리브 그린 `#4F6F52`.
포인트: 테라코타 `#C26A5A`.

**4단계: 이미지 슬롯.**
이미지가 들어갈 자리에 회색 사각형이 놓인다.
각 사각형에 이름표가 있다. `IMG-HERO-01`. `IMG-PROOF-01`.

[캡처: 텍스트만 채워진 상태 — `PENCIL-05_image-slots.png`]

이 이름표가 기획실과 조립라인을 잇는 열쇠다.
와이어프레임의 `IMG-HERO-01`이 이미지 프롬프트의 `IMG-HERO-01`과 연결된다.

사진 기계가 프롬프트를 받으면, 회색 사각형이 사과 사진으로 바뀐다.
AI가 만든 이미지에는 **'AI 생성' 표시가 필요하다** (→ 6절).

[캡처: Hero 섹션 클로즈업 — `PENCIL-07_hero-closeup.png`]

### 스타일 가이드로 자동 분기

여기서 진짜 힘이 나온다.

같은 카피, 같은 구조에 컬러만 바꾸면 분위기가 완전히 달라진다.
v2까지는 이걸 수동으로 했다. 컬러 코드를 직접 고르고, 폰트를 직접 바꿨다.

이제는 **태그 5개면 자동**이다.

Pencil에 200가지 넘는 디자인 방향이 태그로 내장돼 있다.
`get_style_guide(tags)` — 태그 5개를 넣으면 완전한 디자인 사양서가 나온다.
컬러(HEX), 폰트(패밀리+사이즈+웨이트), 간격(gap+padding), 코너 반경, 아이콘까지.

같은 사과 카피에 태그만 바꿨다.
3가지 전혀 다른 페이지가 나왔다.

| 디자인 | 태그 | 폰트 | 느낌 |
|--------|------|------|------|
| E: 에디토리얼 | editorial, monochrome, typography | Instrument Serif (이탤릭) + Inter | 흑백, 매거진 감성, 코너 0px |
| F: 스칸디 웰니스 | scandinavian, clean, pastel, organic | Outfit | 크림색, 그린+테라코타, 라운드 16px |
| G: 럭셔리 골드 | luxury, gold, dark-mode, serif | Cormorant Garamond + Inter | 다크 배경, 골드 악센트, 코너 0px |

[캡처: 에디토리얼 흑백 — `PENCIL-DESIGN-E.png`]
[캡처: 스칸디 웰니스 — `PENCIL-DESIGN-F.png`]
[캡처: 럭셔리 골드 — `PENCIL-DESIGN-G.png`]

카피 한 줄 안 고쳤다. 태그만 바꿨다.
에디토리얼은 Instrument Serif 이탤릭으로 매거진 느낌.
스칸디는 Outfit 산세리프에 둥근 카드와 파스텔 뱃지.
럭셔리는 Cormorant Garamond 세리프에 골드 넘버링.

**매뉴얼 하나 바꾸면 분위기가 바뀐다. 공장은 그대로다.**

이전에 보여준 수동 변형 3개(내추럴, 모던 클린, 프리미엄 다크)와 합치면,
같은 사과 카피로 **6가지 디자인**이 나온 셈이다.

| 변형 | 팔레트 | 방식 | 느낌 |
|------|--------|------|------|
| 트렌드 내추럴 | 크림 + 올리브 + 테라코타 | 수동 | 따뜻하고 자연스러운 |
| 모던 클린 | 흰색 + 블루 | 수동 | 깔끔하고 신뢰감 |
| 프리미엄 다크 | 검정 + 골드 | 수동 | 고급스러운 |
| **에디토리얼 흑백** | **흑백 + 그레이** | **스타일 가이드 자동** | **매거진 감성** |
| **스칸디 웰니스** | **크림 + 그린 + 코랄** | **스타일 가이드 자동** | **부드럽고 안정적** |
| **럭셔리 골드** | **다크 + 골드** | **스타일 가이드 자동** | **클래식 럭셔리** |

## 10. 사과 한 박스, 처음부터 끝까지

사과를 처음부터 끝까지 돌렸다.

| 단계 | 할 일 | 소요 |
|------|------|------|
| 1 | 재료 한 장 (제품 정보) | 10분 |
| 2 | 공장 가동 → 기획 서류 11개 | 10분 |
| 3 | 질문 5개 답변 + 2차 가동 | 15분 |
| 4 | 조립라인 → 페이지 초안 | 15분 |
| 5 | 검수 + 수정 | 10분 |

합계: 약 1시간.

기존: 텍스트만 3시간 + 디자인 외주.
지금: 텍스트 + 디자인 + 이미지까지 1시간.

[캡처: 완성된 사과 상세페이지 전체 — `PENCIL-06_full-page.png`]

검수에서 Hero 헤드라인이 길었다. 18자 이내 권장인데 20자.
카피 파일에서 줄이고 조립라인을 다시 돌렸다. 한 줄에 들어간다.

1차에서 문제를 찾고, 파일을 고치고, 다시 돌린다. 반복이 핵심이다.
같은 공장에 헤드폰 재료를 넣으면? 헤드폰 페이지가 나온다.

## 11. 9단계면 공장이 돌아간다

여기까지 읽고 "이거 어렵겠다" 싶으면.
9단계면 됩니다.

| 단계 | 할 일 | 소요 |
|-----|------|------|
| 재료 만들기 | 상품 1개 골라서 제품 정보 한 장 채우기 | 10분 |
| 첫 가동 | 지시서 붙여넣고 첫 실행 | 15분 |
| 반복 | 질문 5개 답하고, 두 번째 실행 | 15분 |
| 매뉴얼 | 검수에서 반복 걸리는 항목 → 매뉴얼에 추가 | 10분 |
| 검증 | 다른 상품으로 같은 공장 돌려보기 | 15분 |
| **스타일 선택** | **프리셋 5개 중 골라서 태그 지정** | **2분** |
| 조립 | 조립라인 첫 실행: 기획 서류 → 페이지 | 20분 |
| 컴플라이언스 | AI 생성 표시 + 금칙어 검수 + 근거 확인 | 10분 |
| 완성 | 사진 생성 + 최종 검수 + 수정 | 20분 |

9단계면 기획실 + 스타일 분기 + 조립라인 + 컴플라이언스가 돌아간다.
그 다음부터는 상품 하나에 1시간이다.

---

정리하면.

공장에 필요한 건 4가지다.

**1. 재료 한 장** — 제품 정보를 모은다. 모르는 건 비운다.
**2. 지시서** — "이 11개 파일을 만들어줘" + "이 파일로 페이지를 조립해줘."
**3. 매뉴얼** — 톤, 금지 표현, 정책, 시각 검수 기준을 파일로 적어둔다.
**4. 조립 도구** — 레이아웃 기계(Pencil) + 사진 기계(Gemini).

이 4가지가 파일로 있으면, 텍스트도 나오고 페이지도 나온다.
상품이 바뀌면 재료만 바꾼다.
분위기를 바꾸고 싶으면 태그만 바꾼다.
공장은 그대로다.

---

핵심은 도구가 아니다.
재료 한 장, 지시서, 매뉴얼, 조립 도구.
이 4가지를 파일로 만드는 것. 그게 공장이다.

### 부록 H: 스타일 프리셋 카탈로그

태그 조합 하나로 디자인 방향이 결정된다.
Pencil `get_style_guide(tags)`에 넣으면 컬러, 폰트, 간격까지 전부 나온다.

| 프리셋 | 태그 | 용도 | 느낌 |
|--------|------|------|------|
| `fresh-organic` | japanese, minimal, cream, organic, warm, soft-corners | 식품, 뷰티, 라이프스타일 | 따뜻하고 자연스러운 |
| `tech-clean` | modern, clean, blue-accent, whitespace, webapp, sharp-corners | IT, SaaS, 전자제품 | 깔끔하고 신뢰감 |
| `luxury-dark` | luxury, dark-mode, gold-accent, serif, elegant, premium | 프리미엄, 명품, 고가 | 고급스러운 |
| `bold-energy` | bold, neon, dark-mode, electric, vibrant, rounded | 피트니스, 게임, 스트리트 | 에너지 넘치는 |
| `scandi-calm` | scandinavian, pastel, calm, soft-corners, friendly, organic | 웰니스, 키즈, 홈 | 부드럽고 안정적인 |

**사용법:**
설계도(제품 정보 한 장)에 `style_preset: fresh-organic`을 추가하면,
공장이 태그를 읽고 → 스타일 가이드를 호출하고 → 컬러/폰트를 자동 적용한다.

프리셋 5개로 부족하면? 태그를 직접 조합한다.
200+ 태그 중 5~10개를 골라 넣으면 된다.
