# 기고 기획서

## 제목 (안)
클로드 코드로 상세페이지 초안 공장 만들기

## 한 줄 요약
AI 도구 소개가 아니라, 재료 한 장 넣으면 텍스트+디자인+검수까지 자동 생산하는
"상세페이지 공장 시스템"을 9단계로 만드는 실무 가이드.

## 타겟 독자
- 1인 셀러 / 소규모 커머스 운영자
- 마케터 / 콘텐츠 기획자
- AI 도구에 관심 있지만 "1회성 결과"에 불만인 실무자

## 차별점
1. **도구 소개 아님** → 재현 가능한 시스템 설계도
2. **카피만 아님** → 디자인(Pencil)까지 자동 조립
3. **AI 기본법 표시 의무 + 표시광고법 검수 자동화** 내장
4. **실패 시나리오 포함** (AI가 틀리면 어떻게 잡히는지 시연)
5. **부록 8개** → 복사해서 바로 쓸 수 있는 템플릿

## 예상 분량
약 869줄 (부록 A~H 인라인 포함) / 읽기 시간: 본문 15분 + 부록 참조 5분

## 준비 상태
원고 v4.1 폴리시 완료 (`f8587fe`), 디자인 캡처 17장, 딥리서치 10편, 부록 A~H 전부 인라인

## 저자 소개
AI 기반 커머스 자동화 실무자.
Claude Code + Pencil(AI 디자인 도구)로 상세페이지 제작 파이프라인을 설계·운영 중.
"도구 리뷰"가 아니라 "재현 가능한 시스템"을 만드는 데 관심이 있습니다.

## 기대 효과
- 퍼블리 독자가 **복사해서 바로 쓸 수 있는** 워크플로우 제공
- "AI로 상세페이지 자동화"라는 퍼블리 내 **블루오션 영역** 선점
- 부록 템플릿이 재방문·공유를 유도하는 **리텐션 콘텐츠** 역할
