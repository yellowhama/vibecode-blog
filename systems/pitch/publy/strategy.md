# 퍼블리 기고 전략 문서

- 작성일: 2026-02-28
- 목적: 퍼블리 4월 기획안(테마 1) 지원을 위한 주제/문체/실행 전략 확정
- Intent SSOT: `00-INTENT.md`
- 원고 구현 계획(복붙 vs 자동화 비교 포함): `PUBLY_ARTICLE_PLAN.md`

## 1) 목표와 성공 기준

- 목표: 4월 기획안 공고에 맞춰 채택 가능성이 높은 제안서 1개를 제출한다.
- 성공 기준:
1. 독자가 "바로 써먹을 수 있다"고 느끼는 실무 템플릿 포함
2. 정량 결과(시간 절감, 재작업 감소) 제시
3. 실패 사례와 복구 방법까지 포함

## 2) 퍼블리 핵심 타겟 독자

- 1차 타겟: 반복 업무가 많은 실무자(마케터, 기획자, 운영, 영업지원)
- 2차 타겟: 실무 성과를 빨리 내야 하는 주니어~중간 연차
- 공통 니즈:
1. 오늘 바로 적용 가능한 방법
2. 도구 소개보다 업무시간 절감 결과
3. 복붙 가능한 템플릿과 체크리스트

## 3) 퍼블리 맞춤 문체 가이드

- 톤: 친절하지만 단정한 실무형 존댓말
- 원칙:
1. 추상 설명보다 상황-행동-결과 순서로 쓴다.
2. 한 문단에 한 메시지만 넣는다.
3. 도입 5문단 안에 "얻는 결과"를 먼저 제시한다.
- 권장 구성:
1. 문제 공감(독자의 실제 통증)
2. 10분 요약(핵심 3줄)
3. 단계별 실행법
4. 템플릿/프롬프트
5. 실패 케이스와 복구법
6. 1주 적용 플랜
- 분량 목표: 약 1만 자 내외

## 4) 주제 선택 전략

### A안(최우선): 클로드 코드 + API 기반 상세페이지 자동화

- 주제명 가안: "클로드 코드로 상세페이지 제작 80% 자동화: 실무형 AI 에이전트 팀 설계법"
- 채택 근거:
1. 테마 1과 정합성이 가장 높다.
2. 자동화 전/후 수치 제시가 쉽다.
3. 독자가 템플릿 형태로 재사용하기 좋다.
- 핵심 결과 약속:
1. 상세페이지 제작 리드타임 단축
2. 반복작업 감소
3. 검수 누락 감소

### B안(차선): 요청 폭주 상황에서 일정 방어 워크플로우

- 주제명 가안: "갑자기 들어온 일에 휘둘리지 않는 3단계 업무 방어 워크플로우"
- 장점:
1. 직무 확장성이 높다.
2. 공감대가 넓다.
- 보완점: AI 요소를 반드시 구체화해야 테마 1 적합성이 높아진다.

## 5) 3개 소주제 우선순위(현재 기준)

1. 소주제 1(상세페이지 자동화): 글 품질/차별화/증빙 수치 모두 확보 가능
2. 소주제 3(업무 방어 시스템): 독자 풀 확장성 우수
3. 소주제 2(AI 엑셀 매크로): 특정 직무 편중 가능성 존재

## 6) 추가 제안 가능한 주제(예비 카드)

1. 회의록 자동 요약 + 액션아이템 자동 할당 시스템
2. 주간 리포트 자동 생성 파이프라인(수집-요약-시각화)
3. AI 자동화 실패 복구 매뉴얼(깨지는 7가지 지점과 대응)

## 7) 제안서 구성안(퍼블리 제출용)

1. 문제 정의: 기존 방식에서 시간이 새는 지점
2. 왜 지금 필요한가: 독자 상황과 비용
3. 실행 구조: 입력-처리-검수-예외 대응
4. 핵심 템플릿: 프롬프트/체크리스트/운영 룰
5. 성과 지표: 도입 전/후 수치 비교
6. 실패 사례: 실제 시행착오와 복구 절차
7. 적용 플랜: 팀 규모별 1주 도입 가이드

## 8) 이번 주 실행 계획

1. 주제 확정: A안 또는 B안 최종 선택
2. 증빙 데이터 수집: 작업시간, 재작업 횟수, 오류율
3. 제안 메일 작성: 5~8줄 버전 2개
4. 본문 목차 확정: 7개 섹션 + 템플릿 첨부 목록
5. 초안 작성: 1차 원고(약 1만 자)

## 9) 즉시 결론

- 현재 최적 선택은 A안(상세페이지 자동화)이다.
- 제출 메시지는 "AI 도구 소개"가 아니라 "정시 퇴근 가능한 업무 시스템"에 집중한다.
