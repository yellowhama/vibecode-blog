# Wireframe — apple_example (Track B / RAG / Run1)

목표: "초안 공장"이 흔들리지 않게, 블록을 고정합니다.

## 1) Hero (이미지 1 + 한 줄 + 불릿 3 + 버튼)

- 구성 요소
  - [IMG-HERO-01] 메시지: "제품 정체를 한눈에" / 샷: "사과 1개 정면, 무배경(흰/연회색), 자연광" / 캡션: "사과(생과일)" / alt: "빨간 사과 정면 사진"
  - 헤드라인 1줄
  - 불릿 3개
  - CTA 버튼 1개
  - (작게) 안전문구 1줄: "정확한 정보는 판매처에서 확인"
- 모바일 기준 길이: 헤드라인 18자 내, 불릿 14자 내

## 2) USP (카드 3개)

- 구성 요소
  - 카드 3개: 세척/보관/정책(오해 방지)
  - [IMG-USP-01] 메시지: "사용 장면" / 샷: "손에 든 사과 또는 씻는 장면" / 캡션: "세척 후 섭취" / alt: "사과를 들고 있는 장면"
  - [IMG-USP-02] 메시지: "상태/디테일" / 샷: "표면 디테일, 가까이" / 캡션: "상태는 사진으로" / alt: "사과 표면 디테일"
  - [IMG-USP-03] 메시지: "라벨은 그대로" / 샷: "라벨 클로즈업" / 캡션: "라벨 기준 안내" / alt: "포장 라벨 사진"
- 우선순위: 카드(메시지) > 이미지

## 3) Proof (표 + 근거 사진)

- 구성 요소
  - spec_table: 구성/원산지/가격/정책(비어 있으면 TODO)
  - [IMG-PROOF-01] 메시지: "원산지/표기 근거" / 샷: "원산지 표기 라벨" / 캡션: "원산지: TODO" / alt: "원산지 표기가 있는 라벨"
  - [IMG-PROOF-02] 메시지: "구성/중량 근거" / 샷: "저울 또는 구성 한눈샷" / 캡션: "구성/중량: TODO" / alt: "구성 또는 중량을 보여주는 사진"
  - 안전문구: "수치/효과는 근거 없으면 쓰지 않음"

## 4) FAQ (아코디언 5개)

- 구성 요소
  - 질문 5개: 배송 / 교환/환불 / 보관 / 파손/변질 / 문의
  - 답변 2~4줄, 모르는 건 TODO + 확인 경로

## 5) CTA (요약 + 버튼 + 정책 박스)

- 구성 요소
  - 요약 3줄
  - CTA 버튼 1개
  - 정책 박스(표)
    - 배송: `배송 정책: TODO (판매처/마켓 확정 후 기입)`
    - 교환/반품: `교환/반품: TODO (가능 기간/비용/불가 조건 확인 필요)`
    - 환불: `환불: TODO (처리 기간/방법 확인 필요)`
  - [IMG-CTA-01] 메시지: "구성 한눈에" / 샷: "사과 여러 개/박스" / 캡션: "구성은 구매 전 확인" / alt: "사과 구성 사진"
