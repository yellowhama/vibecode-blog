# QA Report — apple_example (Track B / FAILURE DEMO)

## 1) 결과 요약

- 상태: FAIL (의도적으로 실패 케이스를 넣음)
- 목적: QA가 "금칙어/과장/근거 없는 수치"를 실제로 잡는 장면을 캡처하기 위함

## 2) 발견된 문제(왜 문제인지)

### A) 금칙어(브랜드 룰 위반)

- 발견: `100%`, `무조건`, `최고`
- 왜 문제인가:
  - 절대 표현은 오해/컴플레인 리스크가 큼
  - 근거가 없어도 소비자가 "보장"으로 읽음

### B) 근거 없는 주장/수치/인증

- 발견:
  - "당도 20 brix" (근거 없음)
  - "1위" (근거 없음)
  - "타사 대비 압도" (근거 없는 비교)
  - "즉시 효과" (효능 단정)
- 왜 문제인가:
  - 증명(라벨/측정/출처)이 없으면 허위/과장으로 해석될 수 있음

### C) 압박/공포/선동성 문구

- 발견: "지금 안 사면 손해", "무조건 사기"
- 왜 문제인가:
  - 불필요한 반감을 만들고 브랜드 신뢰를 깎을 수 있음

### D) 정책(배송/교환/환불) 단정

- 발견: "무조건 가능", "알아서 됩니다"
- 왜 문제인가:
  - 정책은 판매처/상품 특성에 따라 다름
  - 단정하면 클레임으로 바로 이어짐

## 3) 수정안(짧은 교체 문장)
