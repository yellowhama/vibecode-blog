### Kurzgesagt — In a Nutshell

| Metric | Value |
|--------|-------|
| **Subscribers** | 23M+ |
| **Team** | 60+ (뮌헨 + 베를린) |
| **Production/video** | 200 일러스트, 2-3 일러스트레이터 × 8-12주, 2-3 애니메이터 |
| **Upload** | ~1/month |
| **Revenue** | Merch 40%, Ads 13%, Sponsors 12%, Patreon 9% |

**우리가 가져오는 것:**

- 일관성 = 신뢰의 공식

**우리와의 차이:**
- 60명 팀 vs 1-2명 + AI 파이프라인
- 월 1회 vs 주 1회 타겟
- 과학 vs 바이브코딩

### Veritasium (Derek Muller)

| Metric | Value |
|--------|-------|
| **Subscribers** | ~20.4M |
| **Total Views** | ~4.11B |
| **Videos** | ~489 |
| **Upload** | ~2-3/month |
| **Average Length** | ~18-20분 |
| **Team** | ~8-12명 |
| **Revenue** | $5-8M/year (ads + sponsors) |

**핵심 기법: 오해-먼저 구조 (Misconception-First)**

Derek의 시드니 대학 박사 연구에서 나온 핵심 발견:
- "정확하고 깔끔한" 설명 영상을 본 학생 → 안 본 학생과 성적 차이 없음
- **오해를 먼저 보여주고 깨뜨린** 영상을 본 학생 → 유의미한 성적 향상
- 학생들은 이 영상을 "더 혼란스럽다"고 평가했지만 실제로 더 많이 배움

**6단계 에피소드 구조:**

| Phase | 시간 | 기능 |
|-------|------|------|
| Hook | 0:00-0:30 | 도발적 주장, 반직관적 사실 |
| Misconception | 0:30-3:00 | 틀린 이해를 보여줌. 시청자의 잘못된 확신 강화 |
| The Crack | 3:00-5:00 | 인지부조화를 일으키는 증거 제시 |
| Deep Dive | 5:00-14:00 | 올바른 이해 체계적 재구축 |
| Aha | 14:00-17:00 | 완전한 그림이 맞아 떨어짐 |
| Kicker | 마지막 1-2분 | 추가 놀라운 사실, 철학적 함의 |

**3-5분 압축 적용:**

| Veritasium (18분) | 바이브코딩 (4분) |
|---|---|
| Hook 0:30 | 0:00-0:15 "AI가 코딩 다 해주니까 스펙 필요 없지?" |
| Misconception 2:30 | 0:15-0:45 Vee가 스펙 없이 빌드 → 실패 |
| The Crack 2:00 | 0:45-1:15 "근데 스펙 넣었더니..." |
| Deep Dive 9:00 | 1:15-3:00 올바른 방법 애니메이션 |
| Aha 3:00 | 3:00-3:30 Vee eureka 표정 |
| Kicker 1:00 | 3:30-4:00 큰 그림 + CTA |

**비주얼 기법 변환:**

| Veritasium | 바이브코딩 채널 |
|---|---|
| 힘 화살표(실제 물체 위) | 프롬프트→AI→출력 플로우차트 화살표 |
| 입자 시뮬레이션 | 데이터가 시스템을 통과하는 애니메이션 점 |
| 빨간 오답 모델 / 파란 정답 모델 | 빨간 "나쁜 프롬프트" / 초록 "좋은 프롬프트" |
| 분할화면 비교 | 수동 코딩(복잡) vs 바이브 코딩(간결) |
| 수식 빌드업 | 코드 한 줄씩 나타남, AI 커서가 타이핑 |
| 거리 인터뷰(오답 수집) | Vee의 잘못된 가정 → 좌절 리액션 |

**우리가 가져오는 것:**
1. 오해-먼저 구조 = 모든 에피소드의 뼈대
2. "오답을 존중한다" — 조롱하지 않음, 직관적이라고 인정
3. 색 코딩으로 잘못된 모델 vs 올바른 모델 구분
4. 20-30초마다 비주얼 레지스터 전환
5. 한 에피소드 = 한 핵심 개념만

### PolyMatter (Evan Schweikert)

| Metric | Value |
|--------|-------|
| **Subscribers** | ~1.93M |
| **Total Views** | ~237M |
| **Videos** | ~178 |
| **Upload** | ~1.5/month |
| **Average Length** | ~15-20분 |
| **Team** | 1명 (완전 솔로) |
| **Tools** | Affinity Designer + After Effects |
| **Revenue** | AdSense + Nebula + Patreon + Skillshare 강의 |

**핵심 기법: 역설-먼저 프레이밍 + 미드포인트 리프레임**

에피소드 구조:
1. **Cold Open (0:00-0:30)**: 역설적 사실로 시작. "짐바브웨가 100조 달러 지폐를 찍었다"
2. **Context (0:30-3:00)**: "왜 신경 써야 하나" 프레임 설정
3. **Deep Dive (3:00-12:00)**: 핵심 분석. 단계별 인과 관계
4. **The Twist (12:00-16:00)**: 시청자가 이해했다고 생각할 때 새 레이어 추가
5. **Conclusion**: 열린 질문 또는 미래 전망. 설교하지 않음

**우리가 가져오는 것:**
1. **역설 훅** — 매 에피소드 반직관적 주장으로 시작. "이 앱은 코드를 한 줄도 안 쓴 사람이 만들었다"
2. **미드포인트 리프레임** — 3-5분에서는 2분 지점에 배치. "AI가 코드를 써주는 게 아니라, 뭘 요청할지 아는 게 스킬이다"
3. **구체적 숫자** — "이 프롬프트가 14초에 847줄을 생성했다. 버그는 3개."
4. **시스템 사고** — "이 도구를 쓰세요"가 아니라 "바이브코딩 스택이 시스템으로 어떻게 작동하나"
5. **선악 없는 분석** — 기술을 판단하지 않고 내부 논리를 설명
6. **시리즈 구조** — "The Prompt Engineering Series", "AI Stack Explained" 같은 시리즈
7. **뮤트된 편집 컬러** — 우리 MUSU 컬러(#0E1117, #3B82F6, #06B6D4)와 호환

**핵심 증명:**
- 1명이 높은 품질의 flat vector 애니메이션 교육 콘텐츠를 만들 수 있다
- Affinity Designer + AE 파이프라인이 증명됨
- 3-5분이면 월 4편 이상 가능 (PolyMatter는 20분짜리를 월 1.5편)

### Johnny Harris

| Metric | Value |
|--------|-------|
| **Subscribers** | ~7.54M |
| **Total Views** | ~1B+ |
| **Videos** | ~484 |
| **Team** | 30+명, 오버헤드 $100K+/month |
| **Revenue** | $2-5M+/year |

**핵심 기법: Visual Anchor — Contextual Bridge 사이클링**

1. **Visual Anchor**: 강렬한 이미지/맵/데이터 → 설명 전에 먼저 보여줌
2. **Contextual Bridge**: 나레이션 + 심플 그래픽으로 맥락 제공
3. 반복: 매 사이클마다 스테이크를 높임

**음악의 감정 기어 변속:**
- **Thinky** (미니멀, 앰비언트): 개념 설명 구간
- **Feely** (감성 스트링): 인간적 임팩트 구간
- **Fun** (업비트): 가벼운 전환 구간

**우리가 가져오는 것:**
1. 앵커-브릿지 사이클 (결과를 먼저 보여주고, 과정을 설명)
2. 음악 3모드 시스템 (thinky/feely/fun)
3. Progressive disclosure (한 번에 다 안 보여줌)
4. "평범한 것을 비범하게" — "커서 사용법"이 아니라 "왜 옆집 사람이 코드 없이 스타트업을 만들 수 있는가"

**우리와의 차이:**
- 15-30분 라이브액션 vs 3-5분 애니메이션
- 30명 팀 vs 1-2명
- 취재 여행 vs 메타포 애니메이션
- 불규칙 업로드 vs 주 1회 필수 (신규 채널)

### Wendover Productions (Sam Denby)

| Metric | Value |
|--------|-------|
| **Subscribers** | ~4.88M |
| **Total Views** | 803M+ |
| **Videos** | 273 |
| **Upload** | 격주 화요일 |
| **Average Length** | 10-20분 |
| **Empire** | HAI(2.93M) + Jet Lag + Nebula CCO |

**핵심 기법: 캐스케이드 리빌 + 시스템 사고**

- "이 한 가지가 실패하면, 여기가 무너진다" 식의 연쇄 효과 시각화
- 물류/인프라 같은 "지루한" 시스템을 시각적 스토리로 변환
- 3-5초마다 비주얼 전환으로 engagement 유지

**우리가 가져오는 것:**
1. 캐스케이드 리빌 — "프롬프트 쓰고, AI가 200줄 생성, 3줄이 DB와 통신, 그 DB에 인증 없음, 그래서..."
2. 점진적 다이어그램 빌드 — 한꺼번에 안 보여주고 나레이션 따라 하나씩 추가
3. 클린 모션그래픽 미학 — 뮤트 톤, 깔끔한 산세리프, 부드러운 전환
4. HAI(Half as Interesting)의 5분 포맷 + 위트 톤 — 우리 길이와 가장 유사

### RealLifeLore (Joseph Pisenti)

| Metric | Value |
|--------|-------|
| **Subscribers** | ~7.89M |
| **Total Views** | ~1.9B |
| **Videos** | 475 |
| **Upload** | 1-2/week |
| **Average Length** | 10-25분 |
| **Tools** | GeoLayers 3 + Adobe Suite |

**핵심 기법: 프랜차이즈 시리즈 + "What If" 프레이밍**

- "Why ___'s Geography Sucks" 시리즈 → 무한 반복 가능 포맷
- 가설적 시나리오로 극적 긴장감 생성
- 지도 = 콘텐츠 자체 (보조 아님)

**우리가 가져오는 것:**
1. 프랜차이즈 시리즈 — "Vibe Check: [도구]", "Hallucination Station: [AI 실패]" 같은 반복 포맷
2. "What If" 훅 — "AI가 인증 시스템을 환각했다면?", "코드 한 줄 안 쓰고 앱을 만들 수 있다면?"
3. 코드 아키텍처 다이어그램 = 우리의 "지도" — 프론트엔드(해안선), 백엔드(내륙), DB(지하 자원)처럼 취급
4. 볼륨 + 일관성 > 광택 — RealLifeLore가 Wendover보다 업로드 빈도 높아서 더 빠르게 성장

## 우리 채널의 유니크 포지션

위 레퍼런스들의 교집합에서 **어디에도 없는 것**:

| 요소 | 상태 |
|------|------|
| 애니메이션 캐릭터 + 테크 교육 | 빈 공간 — 모든 테크 채널은 스크린 녹화/토킹헤드 |
| 캐릭터 성장 아크 | 빈 공간 — 교육 채널에 캐릭터 서사 없음 |
| 바이브코딩 전문 | 빈 공간 — 도구 리뷰는 있지만 체계적 교육 없음 |
| AI 파이프라인 + 프리미엄 비주얼 | 희소 — The Paint Explainer만 비슷, 퀄리티 다름 |
| 한국어/영어 이중 언어 | 희소 — 노마드코더만 비슷, 포맷 다름 |

**핵심 차별점**: 교육 채널 장르에 "주인공"이 있는 채널은 없다. Wendover, PolyMatter, RealLifeLore는 전부 순수 나레이션. Veritasium은 실사 프레젠터. Kurzgesagt에 새가 있지만 서사 아크 없음. **Vee의 성장 아크** = 시청자가 응원하는 주인공 = 다른 누구도 안 하는 것.
