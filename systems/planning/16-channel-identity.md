### 레퍼런스 하이브리드

- **Kurzgesagt**: 교육 깊이. 프리미엄 느낌의 단순함.

- **StoryBots**: 질문→모험→답 구조. 캐릭터 단순함. 스타일 전환.
- **Claudius Papirus**: AI 뉴스 타이밍. 다크 배경 + 마스코트. 1인 제작 규모.

## 비주얼 스타일

### 2D Flat Vector (3D 전환)

~~3D Pixar-like clay texture~~ → **Flat 2D vector** (Kurzgesagt 계열)

| 요소 | 스타일 |
|------|--------|
| **배경** | 다크 (#0D1B2A 또는 #0E1117) — Claudius Papirus 참고 |
| **캐릭터** | 밝은 톤, 단순한 실루엣 (썸네일에서도 읽힘) |
| **다이어그램** | ByteByteGo 스타일 — 단계별 애니메이션, 화살표, 아이콘 |
| **컬러** | 토픽별 팔레트 (Kurzgesagt 방식) |
| **코드 데모** | 다크 터미널 + 하이라이트 (Fireship 스타일) |

### 스타일 전환 = 정보 타입 전환 (StoryBots 원칙)

```
캐릭터 장면 → 다이어그램 → 코드 데모 → 캐릭터
```

전환이 곧 "지금 다른 종류의 정보가 나온다"는 시각적 신호.

## 캐릭터

### StoryBots 원칙: 1색 + 1성격 + 1실루엣

캐릭터는 **비주얼 리액션 + 팻말 only**. 음성 없음. 모든 정보 전달은 내레이터.

---

### Vee (재설계)

| 항목 | 설정 |
|------|------|
| **스타일** | 2D flat. 단순한 실루엣 (썸네일에서 3초 안에 읽힘) |
| **1색** | Electric Cyan (#06B6D4) — 채널 메인 컬러 |
| **1성격** | **호기심** — "어? 왜 이러지?" |
| **역할** | 시청자 아바타. 질문을 던지는 쪽. |
| **주체성** | 스스로 궁금해서 파고듦. 누가 시켜서가 아님. |

**패턴 전환:**
- ~~실패 → 강제 학습~~ (삭제)
- **호기심 → 실험 → 발견** (신규)

Vee는 실패로 배우는 게 아니라 "어? 왜 이러지?"에서 시작해서 답을 찾는다.
실패는 과정에서 자연스럽게 일어나지만, 동기는 항상 호기심이다.

---

### Bee (재설계)

| 항목 | 설정 |
|------|------|
| **1색** | Amber (#F59E0B) |
| **1성격** | **귀찮지만 정확함** — 틀린 말 들으면 못 참음 |
| **제약** | 길게 설명 안 함. 핵심 한 줄 + 시각화(팻말/다이어그램)만 |
| **동기** | Bee는 Vee가 쓰는 코드 위에 살고 있음. Vee 코드가 터지면 Bee 집이 터짐. |

**핵심: 이해관계자, 교육자가 아님.**
가르치고 싶어서가 아니라 살려고 끼어듦. 이기적 동기.
