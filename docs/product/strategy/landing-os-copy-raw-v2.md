## Landing Page Wireframe V2

### 블록 1: The Hook (영웅 섹션)

* **배경:** 딥 옵시디언(Deep Obsidian) 블랙
* **최상단 킬러 슬로건 (초대형 폰트):**
> **"AI proposes. MUSU enforces."**
> (AI는 제안할 뿐입니다. 집행은 MUSU가 합니다.)

* **서브 카피 (중간 폰트, 회색):**
> Cursor, Claude Code, OpenDevin... 이 중 2개 이상을 섞어 쓰고 계십니까?
> 버리지 마십시오. 당신의 AI는 그대로 두되, 그들이 뛰노는 '운영체제(OS)'만 갈아 끼우십시오.
> 세팅 지옥은 끝내고, 통제권과 지능의 한계를 돌파하십시오.

* **CTA 버튼:** `[ 기존 툴 설정 1초 만에 가져오기 (Windows용 다운로드) ]`

### 블록 2: 뱀파이어 전략 (Zero Setup)

* **타이틀:** 세팅 지옥의 끝. 당신이 쓰던 툴, 1초 만에 흡수합니다.
* **상세:** 새로운 툴 쓸 때마다 JSON 파일 만지실 겁니까? MUSU는 설치 즉시 당신이 기존에 맞춰둔 도구(MCP)와 스킬(`.cursorrules`)을 완벽하게 스캔하여 통제망 안에 쓸어 담습니다. 전환 비용(Switching Cost)은 제로입니다.

### 블록 3: 기적의 연산 엔진 (The P15 Architecture) — NEW

* **레이아웃:** 3열 카드형 UI
* **타이틀:** 당신의 AI가 유독 비싸고 멍청했던 이유. MUSU가 뜯어고쳤습니다.

**카드 1: 95% API 요금 삭감 (Holodeck Virtual Shell)**
> "로그 파일 하나 찾겠다고 100MB 텍스트를 통째로 AI 입에 쑤셔 넣고 13만 토큰을 태우십니까? MUSU의 'Holodeck' 가상 쉘은 AI가 직접 `grep`과 `awk`를 쳐서 필요한 데이터만 파싱하게 만듭니다. API 요금은 95% 삭감되고, AI는 더 빠르고 날카로워집니다."

**카드 2: 금붕어 기억력 치료 (Block Chain Chunking)**
> "업계 표준 RAG 툴들은 코드를 500글자씩 무식하게 썰어버립니다. 서론인지 결론인지도 모르죠. MUSU는 함수의 선언부나 마크다운 헤더 등 '의미 경계' 단위로 코드를 분해하고, 부모-자식 체인(족보)을 연결합니다. AI가 코드의 완벽한 문맥을 이해하게 만드십시오."

**카드 3: 절대 무사고 샌드박스 (Time Stone Simulation)**
> "Mistakes don't ship. AI가 짠 코드를 내 파일에 바로 덮어쓰다 밤새운 적 있으십니까? MUSU는 뒤에 마련된 가상의 시뮬레이션 룸(Time Stone)에서 N개의 전략을 먼저 돌려보고, 스스로 에러를 고치게 만듭니다. 오직 검증된 완벽한 결과물만 하드디스크에 기록됩니다."

### 블록 4: 무자비한 교도관 (The Warden) & 하이브링크 망 (HiveLink)

* **레이아웃:** 좌우 분할 다이어그램
* **좌측 (통제):** "AI에게 백지수표를 쥐여주지 마십시오." — AI가 시스템 파괴 명령어를 시도하면? MUSU가 중간에서 패킷을 뜯어보고 즉시 손모가지를 날립니다 (BLOCK).
* **우측 (원격):** "스타벅스의 똥컴이, 댁의 4090 GPU를 부려먹습니다." — 카페에서 가볍게 명령만 내리십시오. 무거운 영상 렌더링은 집에 있는 데스크탑이, 기밀 데이터 분석은 사무실의 NAS가 처리합니다.

### 블록 5: 철통 보안 (Zero Data Leak)

* **타이틀:** 당신의 소스코드는 단 1바이트도 우리의 서버로 올라가지 않습니다.
* **상세:** MUSU는 통제할 뿐, 훔쳐보지 않습니다. 우리가 가져가는 건 결제용 이메일뿐입니다. 당신의 짠 코드, 실행되는 파일은 영원히 당신의 로컬 PC 안에서만 숨 쉽니다.

### 블록 6: 최종 다운로드 압박 (The Final Push)

* **배경:** 완전한 암흑(Black) 공간에 덩그러니 놓인 다운로드 버튼 하나.
* **카피:**
> "당신의 툴은 버리지 마십시오. 통제권만 넘기십시오."
> 세팅에 주말을 낭비하는 짓은 오늘로 끝입니다.

* **CTA:** `[ MUSU OS 다운로드 (Windows .exe) ]`
* **캡션:** "설치 즉시 기존 설정을 자동으로 찾아냅니다."

## 핵심 원칙: 랜딩에서 돈 얘기 금지

> 랜딩 페이지의 유일한 목적은 **"일단 무지성으로 .exe 파일을 다운로드하게 만드는 것"**이다.
> 돈 얘기는 유저가 앱을 깔고, 타사 세팅을 흡수해서 "와 미친 개쩐다"라고 감탄하는 바로 그 순간(Aha Moment), 즉 **앱 내부(In-App)**에서 조용히 꺼내야 맞다.

## 오덕 포인트 vs 마케팅 포인트 판정

### 1. 도르마무 시뮬레이션 (Time Stone)

* ❌ **오덕:** "우리는 Holodeck 인스턴스를 N개 띄워서 에러 점수를 -100점, 성공을 +50점으로 스코어링하는 Time Stone 아키텍처를 구현했습니다."
* ✅ **마케팅:** **"AI가 친 사고 수습하느라 주말 날리셨습니까?"** + "Mistakes don't ship."

### 2. 우로보로스 (BitNet + Loop LLM)

* ❌ **오덕:** "CLI 대비 120배 빠른 BitNet 1.58-bit 모델에 엔트로피 정규화를 적용해 우로보로스 루프를 돌립니다."
* ✅ **마케팅:** **"비싼 클로드 API, 단순 노가다에 태우지 마십시오."** + "API 요금은 0원, 결과는 GPT-4급."

### 결론: "백조의 발차기는 숨기고, 우아함만 팔아라"

유저가 지갑을 여는 이유:
1. **"내 파일 안 망가뜨리네? (안전성)"**
2. **"API 토큰값 덜 나오네? (가성비)"**

## 킬러 카피: "생각은 Gemini Pro가. 행동은 MUSU가."

### 3단 콤보 카피 (Hero Section용)

```
[1줄차] 생각은 Gemini Pro가. 행동은 MUSU가.
[2줄차] 코딩, 아키텍처 설계, 복잡한 문제 해결...
        무거운 생각은 세계 최고의 지능(Gemini, Claude)에게 맡기십시오.
        하지만 그 똑똑한 뇌가 당신의 컴퓨터를 직접 건드리게 두지는 마십시오.
[3줄차] 시스템에 명령을 내리고, 코드를 수정하고, 파일을 지우는 모든 '행동'은
        철저하게 통제된 MUSU의 샌드박스 안에서만 허락됩니다.
```

### 왜 완벽한가

1. **구체적 고유명사**: "AI"가 아니라 "Gemini", "Claude" — 유저가 매달 결제하는 이름
2. **비경쟁 포지셔닝**: Cursor/Claude Code가 "우리가 제일 똑똑해!"라고 싸울 때, MUSU는 "손발은 내가 할게"
3. **성장 연동**: LLM이 똑똑해질수록 → 통제 수요 ↑ → MUSU 필요성 ↑

### 동네 아저씨 버전

> "야, 폰 노이만 할아버지가 살아 돌아와서 코딩해 준다고 해도, 그 양반이 내 컴퓨터 포맷 버튼 누르는 건 막아야 될 거 아니야?"

## 벤 삼촌의 법칙: "큰 힘에는 큰 책임"

### Great Power (LLM) vs Great Responsibility (MUSU)

| Great Power (LLM) | Great Responsibility (MUSU) |
|---|---|
| Gemini가 코드를 짜고 시스템 설정을 바꾼다 | Warden이 허락 없는 행동을 즉시 차단 |
| AI의 결정 무게가 무거워진다 | Intent를 쇠사슬로 묶고 변이를 감시 |
| 100만 토큰으로 시크릿 키를 외부 전송 가능 | DLP가 비밀번호/키 유출 자동 차단 |

### 성장 공식

```
AI 지능 ↑ → AI가 할 수 있는 행동 범위 ↑ → 사고 스케일 ↑ → 통제 수요 ↑ → MUSU 필요성 ↑
```

3가지 축:
1. **지능 ↑ → 책임 ↑ (Warden)**: AI가 "내 컴퓨터 비번 알려줘" → 넙죽 믿으면 털림
2. **지능 비용 ↑ → 잔머리 가치 ↑ (Holodeck)**: 비싼 모델일수록 토큰 다이어트 ROI 커짐
3. **제안 빈도 ↑ → 필터 필요 ↑ (Time Stone)**: 똑똑할수록 제안 많아짐 → 전부 수용하면 난장판

### 동네 아저씨 버전

> "야, 칼이 날카로울수록 칼집이 튼튼해야 하는 거 아녀? 앤스로픽이나 구글 애들이 맨날 '우리 칼이 더 잘 들어요!'라고 광고할 때, 우리는 '그 칼 쓰다가 니 손 안 베이게 내가 특수 장갑(MUSU) 만들어줄게'라고 하는 거지. 칼이 면도날처럼 날카로워질수록 우리 장갑은 더 잘 팔릴 수밖에 없당께."

## Warden 샷건: 프론트엔드 시각화 설계

### 3단계 플로우

**1. 인지 (Detection):**
- AI 명령어 가로채기 → `warden.consent.requested` → "Warden 스캔 중..."
- 아재: "잠깐, 이 자식이 지금 우리 집 안방(Root) 열쇠 달라고 하는데?"

**2. 격발 (Hard Block):**
- 위험 감지 → `warden.execution.blocked` → 붉은 HARD BLOCK 배너

| 공격 벡터 | 에러 코드 | 유저 메시지 |
|---|---|---|
| 관리자 권한 탈취 시도 | `PRV-001` | "AI가 영구 관리자 권한을 요구했습니다. 즉시 차단합니다." |
| 쉘 우회 및 명령어 체이닝 | `PRV-010` | "비정상적인 명령어 조합이 감지되었습니다. 실행을 거부합니다." |
| 알 수 없는 위험 명령 | `PRV-099` | "허가되지 않은 시스템 접근 시도입니다." |

**3. 훈육 (Audit):**
- 차단 사유 공개 + 민감 정보 `***redacted***` 마스킹 → 감사 로그 기록
- 아재: "이놈이 니 비번까지 훔쳐보려고 했어. 내가 일단 별표 처리해서 장부에 적어놨어."

### 모바일 원격 승인

- 푸시 알림: "AI가 시스템 설정을 바꾸려고 합니다. 허락할까요?"
- 버튼: `Approve` / `Reject` 만 존재
- 보안: 모바일에서 비밀번호/토큰 입력 완전 차단

### 동네 아저씨 버전

> "샷건이 왜 샷건이겠어? 한 번 쏘면 그 근처는 얼씬도 못 하게 만드는 거 아녀. 우리 Warden이 PRV-001 같은 거 딱 감지하면, '어이쿠 실수하셨네요'가 아녀. 그냥 그 자리에서 실행 파일을 튀겨버리고 유저한테 고발하는 거지."

> 나쁜놈들 쏴버리라고 샷건도 들려줄라 그랬는데, 그건 불법이라고 안된대서 못했어.

> "원래는 이상한 짓 하는 AI나 해커놈들 쏴버리라고 서버에 진짜 샷건을 달아놓고 싶었는데, 그건 불법이라 내가 철창 간다더라? 그래서 아쉬운 대로 '접근 차단(BLOCK)' 버튼에 전기 충격기만 달아놨어. 허튼수작 부리면 연결된 패킷째로 튀겨버릴 거니까 얌전히 써."

## 마케팅 관점: 4연속 카운터펀치

유저가 랜딩 페이지를 읽으며 맞는 4번의 펀치:

1. **공감 & 호기심:** "맞아, 나 커서랑 클로드 섞어 쓰는데? 세팅 다 가져와 준다고?"
2. **비용 & 성능 충격:** "미친, 가상 쉘 돌려서 토큰값 95% 아껴주고, 시뮬레이션 돌려서 에러도 잡아준다고?"
3. **편의 & 보안:** "밖에서 폰으로 집 컴터 조종하는데, 데이터 유출도 없네."
4. **다운로드:** → 무지성 .exe 다운로드
