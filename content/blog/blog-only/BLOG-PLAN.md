## 발행 로드맵

### ~~Phase 0: 아까운 B급 승급~~ — 완료

```
048 ✅ → 035 ✅ → 036 ✅ → 000 ✅ → 043 ✅
```

5편 전부 A 승급 완료. 즉시 발행 가능.

### Phase 1: A급 즉시 발행 (9편)

```
1차: 027 (골드러시) → 048 (Hinton) → 035 (Claude 10배)
2차: 009 (GitHub 레고) → 006 (복순이) → 036 (AI 지혜)
3차: 043 (벡터 DB) → 000 (프롤로그/About)
보류: 012 (Spec Kit 상태 확인 후)
```

**1차** — 범용 어필 3편. 비개발자도 읽힘. 소셜 공유 최적화.
**2차** — 실용+케이스+철학. 구독자 전환용.
**3차** — 기술+소개. 블로그 기반 콘텐츠.

### Phase 2: B급 시리즈 발행 (수정 30분 이내)

```
프롬프트 3부작: 030 → 025 → 035(이미 A)
철학편 4부작: 048(이미 A) → 023 → 022 → 036(이미 A)
```

**이유:** 시리즈 묶음으로 발행하면 체류시간↑, 구독 전환↑
A 승급 완료된 035, 048, 036이 시리즈 앵커 역할.

### Phase 3: 업데이트 후 발행

```
AI 전쟁통: 032 → 033 → 029 → 026 → 044
Claude Code: 016 → 017
실전: 007 → 008
```

**이유:** 시의성 의존도 높아서 발행 시점에 재확인 필수.

### Phase 4: 결정 보류

```
004 (Spec Kit 상태 확인 후)
012 (Spec Kit 상태 확인 후)
001 (블로그 구조에 통합)
```
