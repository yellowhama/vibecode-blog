# AI 바이브 코딩의 환각을 잡는 단축키 – Subagent + `/review` 완벽 가이드

**다섯 줄 요약** 

- AI 코딩의 최대 리스크는 **환각(Hallucination)** — 이미 구현된 걸 새로 만드는 실수.
- “3도 틀린” 문장 하나가 프로젝트를 10시간 뒤틀리게 만든다.
- `/review`를 작업 단위마다 실행하면, 즉시 오류·누락·재구현을 자동 점검 가능.
- Subagent(시니어 코드리뷰 AI)를 붙이면, 오픈소스 엔진 누락도 탐지한다.
- **결과:** 작업 시간 7시간 → 2시간, 생산성 3.5배 상승.

## AI는 100% 환각을 일으킨다

바이브코딩을 하다 보면 꼬인다. 100%.

AI는 한 번씩 환각을 일으키고, 그 환각에 사로잡혀 혼자 엉뚱한 일을 한다.

그 한 번의 엉뚱한 일이 수정되지 않고 5-10시간 작업했다고 생각해보자.

**환장한다. 진짜.**

하고 뒤통수를 때리고 싶어진다. 진짜로.

## "3도 틀린 설명"은 감지할 수 있다

제일 큰 문제는 **난 코드를 모른다.**

대신 읽을 수 있는 건, **Claude Code가 나에게 일 끝나고 보고를 할 때, 그 설명글.**

갑자기 뜬금없이 **정말 미묘하게 틀린 부분**이 있을 때가 있다.

정말 **각도기로 재면 한 3도 정도 틀린** 것 같은 그 설명글.

**그걸 놓치면 안 된다.**

3도 틀린 방향으로 10시간 가면, **아예 다른 도시다.**

---

### 그 "3도 틀린 설명"의 예시

**정상적인 보고:**

```
"오픈소스 엔진의 TacticsCalculator를 래핑했습니다."

```

**3도 틀린 보고:**

```
"전술 계산 시스템을 구현했습니다."

```

**차이 보이나?**

- 정상: "래핑했다" (엔진 재사용)
- 3도 틀림: "구현했다" (새로 만들었다?)

이 차이가 **3시간짜리 삽질의 시작점**이다.

## Subagent

### Subagent가 뭔데?

일반 Claude Code는 "만능 개발자"

Subagent는 **"코드 리뷰만 10년 한 시니어 개발자"**

---

### 설정은 2단계

### **1단계: 기본 가이드 만들라고 시키기**

```
Claude야,

웹 리서치해서
Subagent로 코드 리뷰하는 애
어떻게 만드는지 조사하고

그거 문서화해서 가이드 만들어.

파일: .claude/agents/pragmatic-code-review.md

```

Claude가 알아서:

- 웹 검색하고
- 베스트 프랙티스 찾고
- 가이드 만든다

---

### **2단계: 내 프로젝트에 맞게 추가**

```
ㅇㅋ 이 가이드대로 만드는데,

이거 꼭 넣어:
- 우리 게임 엔진 빼먹었는지 꼭 확인
- "새로 구현" 같은 단어 나오면 Critical 표시
- 오픈소스 래핑 안 했으면 경고

```

끝.

---

### 실제로 시킨 예시

```
나: "Subagent 코드 리뷰 시스템 만들어.
    웹에서 베스트 프랙티스 찾아서.

    우리 프로젝트 특징:
    - 축구 시뮬레이션 게임
    - 오픈소스 엔진 사용 중
    - 엔진 래핑 방식으로 통합

    특히 체크할 것:
    - 엔진 함수 빼먹었는지
    - 새로 구현한 건 아닌지
    - 래핑 안 한 건 아닌지"

Claude: "네!
       웹 리서치 시작합니다...

       (3분 후)

       가이드 문서 생성 완료:
       .claude/agents/pragmatic-code-review.md

       7단계 리뷰 프레임워크로 구성했고,
       엔진 통합 체크 항목 추가했습니다."

```

**끝.**

## 6. 실전: "3도 틀림" 감지 키워드

### 빨간 신호

```
❌ "새로 구현했습니다"
❌ "새로 만들었습니다"
❌ "계산 로직을 추가했습니다"
❌ "함수가 없습니다"

```

### 정상 신호

```
✅ "래핑했습니다"
✅ "엔진 함수를 사용했습니다"
✅ "기존 구현을 확장했습니다"

```

## 7. Before vs After

```
작업 5시간 → 에러 발견 → 다 엎기 2시간 = 7시간

```

### After (매번 `/review`)

```
작업 30분 → /review (3분) → 수정 5분 = 38분
× 3회 = 약 2시간

```

**절약: 5시간**

## 8. 핵심 정리

### 문제

- AI는 환각 일으킴
- 3도 틀린 방향으로 10시간 가면 다른 도시

### 해결

- Ctrl+S처럼 `/review` 습관화
- Subagent가 체계적으로 분석
- "3도 틀림" 키워드 감지

### 설정 (2단계)

**1단계: 기본 가이드**

```
"웹 리서치해서 Subagent 코드 리뷰 시스템 가이드 만들어"

```

**2단계: 커스터마이징**

```
"이거 추가해:
- 우리 엔진 빼먹었는지 체크
- '새로 구현' 단어 나오면 Critical"

```

### 사용

```
작업 끝날 때마다 /review

```

### 효과

- **Before**: 7시간
- **After**: 2시간
- **절약**: 5시간
