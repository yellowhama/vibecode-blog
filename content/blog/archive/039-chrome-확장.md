# 039 Claude가 내 브라우저를 직접 조작한다고?

## **Claude가 내 Chrome을 직접 조작한다 — Playwright 시대가 끝난 이유**

**AI 브라우저 자동화의 새로운 기준, Claude Chrome 확장 완전 분석**

---

### TL;DR (3줄 요약)

- **Claude Code가 이제 내 Chrome 브라우저를 직접 조작한다.** 클릭, 스크롤, 입력, 스크린샷 전부 가능.
- **기존 도구(Playwright, Puppeteer)는 설치도 복잡하고, 내 로그인도 안 되고, 토큰도 폭발했다.**
- **이번 공식 Chrome 확장은 다르다.** 내 실제 브라우저에서 작동하고, 구글 로그인 상태도 유지된다.

---

## AI가 브라우저를 직접 조작한다는 건 무슨 뜻일까?

보통 Claude한테 이런 건 안 된다:

**나**: "내 웹사이트 들어가서 회원가입 버튼 눌러봐"
**Claude**: "저는 웹사이트를 직접 조작할 수 없습니다."

**나**: "이 구글 폼에 데이터 100개 입력해줘"
**Claude**: "저는 폼을 직접 작성할 수 없습니다."

**나**: "내 앱 UI 테스트해줘. 버튼 다 눌러보고 깨진 거 있나 확인해"
**Claude**: "스크린샷을 보내주시면 분석해드리겠습니다."

Claude는 **정보는 검색할 수 있지만, 브라우저를 직접 조작하는 건 못 했다.**

검색해서 알려주는 건 되는데, 클릭하고 입력하고 스크롤하는 건 안 됐다.

**눈은 있는데 손이 없는** 상태.

---

## 브라우저 자동화 도구란 무엇이고 왜 필요했을까?

이 문제를 해결하려고 **Playwright**랑 **Puppeteer**가 나왔다.

쉽게 말해 **"코드로 브라우저를 조작하는 도구"**다.

```
"구글 들어가서"
"검색창에 '날씨' 입력하고"
"검색 버튼 클릭해"

```

이걸 코드로 짜면 컴퓨터가 알아서 브라우저를 조작한다.

원래는 개발자들이 **자동 테스트**할 때 쓰던 거다.

"버튼 누르면 진짜 작동하나?"를 사람이 일일이 클릭하기 귀찮으니까.

그래서 **Claude한테 이 도구를 연결**하면?

**나**: "내 웹사이트 테스트해줘"
**Claude**: (브라우저 열고, 클릭하고, 분석하고...)

이론상으로는 완벽했다.

---

## Playwright와 Puppeteer는 왜 실사용에서 실패했을까?

실제로 써보니까 **진짜 별로였다.**

### 환경/비용 문제

- **설치 지옥**: npm, 터미널, 에러... 초보가 하려면 하루 걸림
- **토큰 폭발**: 페이지 분석할 때 HTML 전체를 읽어서 토큰 수만 개 증발
- **스크린샷 지옥**: 프로젝트 폴더에 스크린샷 수십 장 쌓임

### 실사용 불가 문제

- **로그인 안 됨**: 새 브라우저가 열려서 구글, 네이버, 회사 사이트 전부 로그인 풀림
- **정작 클릭 실패**: 버튼 찾아서 클릭하라고 했는데 "클릭에 실패했습니다" ← 이게 결정타

설치하느라 2시간, 설정하느라 1시간, 결과는 실패.

**"그냥 내가 직접 클릭하는 게 빠르다"**

그래서 브라우저 자동화를 포기했었다.

---

## Claude Chrome 확장은 기존 도구와 뭐가 다를까?

2025년, Anthropic이 **공식 Chrome 확장**을 출시했다.

이번엔 진짜 다르다.

| 항목 | Playwright/Puppeteer | Claude Chrome 확장 |
| --- | --- | --- |
| 설치 | 터미널 필수, 복잡함 | **클릭 몇 번, 5분** |
| 내 로그인 | ❌ 매번 새 브라우저 | ✅ **유지됨** |
| Google Docs | ❌ 접근 불가 | ✅ **편집 가능** |
| 스크린샷 | 폴더에 쌓임 | 깔끔하게 관리 |
| 만든 곳 | 커뮤니티 | **Anthropic 공식** |

핵심은 **"내가 쓰는 Chrome 그대로"** 작동한다는 거다.

구글 로그인? 됨. 네이버 로그인? 됨. 회사 내부 사이트? 됨.

---

## Claude Chrome 확장으로 실제로 무엇을 할 수 있을까?

### 1. 웹사이트 UI 테스트

**나**: "내 랜딩 페이지 버튼 다 작동해?"
**Claude**: (전부 클릭해봄) "3번째 버튼이 안 눌립니다."

### 2. 반복 작업 자동화

**나**: "이 스프레드시트 데이터를 저 폼에 100번 입력해줘"
**Claude**: (알아서 반복)
**나**: (커피 마심)

### 3. 로그인 상태 폼 테스트

**나**: "구글 폼에 이 데이터 입력해줘"
**Claude**: (내 구글 계정으로 로그인된 상태에서 바로 입력)

예전엔 "로그인이 안 되어 있습니다"가 끝이었는데, 이제 진짜 된다.

> 👉 그 외에도 이런 게 된다
> 
> - 스크래핑 (가격/리스트 수집)
> - 경쟁사 사이트 모니터링
> - 콘솔 에러 분석
> - UI 비교 분석

## Claude가 브라우저를 조작해도 못 하는 일은 무엇일까?

### ❌ 안 되는 것

- **캡차 인증**: "로봇이 아닙니다" 직접 풀어야 함
- **로그인 대행**: 미리 로그인해둔 상태에서 작업 시켜야 함
- **결제 클릭**: 돈 관련은 당연히 직접

### ⚠️ 아쉬운 점

- **Chrome만 지원** (Brave, Edge 안 됨)
- **프로필 문제**: 여러 프로필 쓰면 엉뚱한 게 열릴 수 있음
- **오래 돌리면 끊김**: Chrome 정책(Manifest V3) 때문
