## [CLAUDE.md](http://claude.md/) 작성법 완벽 정리: 개발 생산성을 높이는 Claude 활용

## TL;DR (3줄 요약)

- **CLAUDE.md는 Claude Code가 항상 읽는 "이 인간 사용설명서"다.**
- 핵심 규칙만 남겨 500줄 → 87줄로 줄이면, 토큰 절약 + 반복 설명 제거 효과가 크다.
- 프로젝트가 진화할 때마다 CLAUDE.md를 업데이트하면, AI가 진짜 "나를 아는 파트너"가 된다.

## CLAUDE.md가 뭔데?

프로젝트 루트에 놓는 단 하나의 파일. Claude가 매번 자동으로 읽는 파일이다.

새 팀원이 왔을 때 뭐라고 설명하나?

"나는 Python 쓰고, 테스트는 pytest로 하고, production 폴더 건드리면 화낸다..."

이걸 파일로 만든 거다. 단, 사람이 아니라 AI를 위한.

그러니까 Claude Code가 읽는 **"이 인간 사용설명서"**다.

이 인간, 즉 사용의 취향을 적는 파일

**나라는 인간의 취향집**이다.

## 왜 "이 인간 사용설명서"인가?

Claude는 매번 나를 모른다. 처음 만난 사람처럼.

"안녕하세요, 무엇을 도와드릴까요?"

아니 우리 어제도 Python으로 코딩했잖아...

CLAUDE.md가 있으면?

"아, 당신은 Python 쓰는 사람이시군요. snake_case 좋아하시고. production 건드리면 화내시는."

드디어 나를 아는 것처럼 행동한다.

"이거 줄여줘"

복순이, Lazy Quant 같은 데이터 처리 프로젝트는 속도가 중요하니까.

그럼 코딩 컨벤션도 넣어야겠다 싶었다. 

인터넷에서 찾은 코딩 컨벤션을 복사해서 보여줬다.

"Rust 컨벤션도 추가해줘"

추가했다.

"SpecKit도 기본으로 쓰자"

추가했다.

## 컨벤션 고르는 법

나처럼 헷갈리지 마라.

1. **프로젝트 언어 확인**
    - Python? → Python 컨벤션
    - JavaScript? → JS 컨벤션
    - 모르겠다? → Claude한테 물어봐
2. **Claude한테 시키기**
    
    ```
    "우리 프로젝트 분석해서 컨벤션 만들어줘"
    
    ```
    
3. **검증**
    
    ```
    "이 컨벤션 맞아?"
    
    ```
